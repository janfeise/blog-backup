使用sort但原数组不变异

阅读时间约 16 分钟 · 字数 3010

在 JavaScript 中，Array.prototype.sort() 会 直接修改原数组（即“变异”/mutation）。如果希望排序 不影响原数组，可以通过以下方法生成一个 新的排序数组，保持原数组不变：

# 方法 1：使用 [...array].sort()（推荐）

通过 展开运算符（Spread Operator）创建原数组的浅拷贝，再对新数组排序：

javascript 
const originalArray = [3, 1, 4, 2];
const sortedArray = [...originalArray].sort(); // 原数组不受影响

console.log(originalArray); // [3, 1, 4, 2]（未改变）
console.log(sortedArray);    // [1, 2, 3, 4]

# 方法 2：使用 array.slice().sort()

通过 slice() 创建原数组的浅拷贝（无参数时复制全部元素）：

javascript 
const originalArray = [3, 1, 4, 2];
const sortedArray = originalArray.slice().sort();

console.log(originalArray); // [3, 1, 4, 2]
console.log(sortedArray);    // [1, 2, 3, 4]

# 方法 3：Array.from(array).sort()

使用 Array.from() 生成新数组：

javascript 
const originalArray = [3, 1, 4, 2];
const sortedArray = Array.from(originalArray).sort();

console.log(originalArray); // [3, 1, 4, 2]
console.log(sortedArray);    // [1, 2, 3, 4]

# 方法 4：concat() + sort()

通过 concat() 合并空数组生成新数组：

javascript 
const originalArray = [3, 1, 4, 2];
const sortedArray = originalArray.concat().sort(); // concat() 无参数时返回浅拷贝

# 方法 5：JSON 序列化（深拷贝，适用于复杂数据）

如果数组包含对象等引用类型，且需要 深拷贝（完全独立的新数组）：

javascript 
const originalArray = [{ id: 3 }, { id: 1 }, { id: 4 }];
const sortedArray = JSON.parse(JSON.stringify(originalArray)).sort((a, b) => a.id - b.id);

console.log(originalArray); // [{ id: 3 }, { id: 1 }, { id: 4 }]（未改变）
console.log(sortedArray);    // [{ id: 1 }, { id: 3 }, { id: 4 }]

⚠️ 注意：此方法性能较差，且无法拷贝函数、undefined 等特殊值。

# 对比总结

方法 代码示例 适用场景 是否深拷贝
展开运算符 [...arr].sort() 简单数组（推荐） ❌
slice() arr.slice().sort() 简单数组 ❌
Array.from() Array.from(arr).sort() 简单数组 ❌
concat() arr.concat().sort() 简单数组 ❌
JSON 序列化 JSON.parse(JSON.stringify(arr)).sort() 复杂对象数组 ✅

# 为什么需要避免原数组变异？

  • 不可变性（Immutability）：函数式编程中，保持数据不变更安全，避免副作用。
  • 调试友好：原数组未被修改时，更容易追踪数据变化。
  • React/Vue 等框架：状态更新依赖不可变数据，直接修改可能导致渲染问题。

# 示例：按对象属性排序（不改变原数组）

javascript 
const users = [
  { name: "Alice", age: 30 },
  { name: "Bob", age: 25 }
];

// 按 age 升序排序（生成新数组）
const sortedUsers = [...users].sort((a, b) => a.age - b.age);

console.log(users);       // 原数组不变
console.log(sortedUsers); // [{name: "Bob", age: 25}, {name: "Alice", age: 30}]

# 总结

✅ 最佳实践：

  • 对简单数组，用 [...array].sort() 或 array.slice().sort()。
  • 对复杂对象数组，用深拷贝（如 JSON.parse(JSON.stringify())）+ sort()。

避免直接使用 array.sort()，除非你明确需要修改原数组！
