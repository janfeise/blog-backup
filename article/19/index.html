轮播图

阅读时间约 22 分钟 · 字数 4224

# 效果

点击按钮时，图片滑动

# 实现思路

由于：currentSlide 的 translateX 值始终为 0%，因此

js 
slides.forEach((slide, index) => {
  slide.style.transform = `translateX(${100 * (index - currentSlide)}%)`;
});

# 思维导图

一级主题 二级主题 说明
核心思想 translateX 移动 通过计算偏移量决定幻灯片位置
跳转函数 goToSlide(index) 根据索引跳转到对应的 slide
状态管理 currentSlideIndex 记录当前显示的幻灯片索引
用户交互 左右按钮、键盘、dot 左右按钮 ±1，键盘方向键，点击 dot 切换
循环逻辑 边界处理 到最左跳到最右，到最右跳到最左
dots 动态生成与激活状态管理 动态生成 dots，点击 dot 定位对应幻灯片

# 一、核心思想

轮播图的本质： 通过 CSS 的 transform: translateX(...) 来移动幻灯片位置。

  • 每个幻灯片都有固定的“索引”（index），这个索引不会变。
  • 通过计算 (index - currentSlideIndex) * 100%，就能确定该幻灯片相对舞台的位置。

📌 总结：舞台只显示 translateX(0%) 的那一张。

# 二、跳转 slide 函数

goToSlide(targetIndex)：根据索引跳转到对应的 slide。

js 
const goToSlide = function (targetIndex) {
  slideElements.forEach((slide, index) => {
    slide.style.transform = `translateX(${100 * (index - targetIndex)}%)`;
  });
};

# 三、状态管理

js 
let currentSlideIndex = 0;
const totalSlides = slideElements.length;
  • currentSlideIndex → 当前显示slide的索引
  • totalSlides → 总共有几张图

# 四、用户交互：左右切换

# 1. 点击左按钮

js 
const showPreviousSlide = function () {
  currentSlideIndex = currentSlideIndex === 0 ? totalSlides - 1 : currentSlideIndex - 1;
  renderSlide(currentSlideIndex);
};
prevButton.addEventListener('click', showPreviousSlide);

# 2. 点击右按钮

js 
const showNextSlide = function () {
  currentSlideIndex = currentSlideIndex === totalSlides - 1 ? 0 : currentSlideIndex + 1;
  renderSlide(currentSlideIndex);
};
nextButton.addEventListener('click', showNextSlide);

# 五、按键切换 slide

除了按钮，我们也可以使用 键盘方向键 来切换 slide：

js 
document.addEventListener('keydown', function (e) {
  if (e.key === 'ArrowRight') showNextSlide();
  if (e.key === 'ArrowLeft') showPreviousSlide();
});

这样，用户无需鼠标点击，只需通过 ← / → 键即可切换。

# 六、通过 dots 点切换

# 1. 动态生成 dot

根据 slide 的数量，动态生成对应数量的小圆点：

js 
const createDots = function () {
  dotsContainer.innerHTML = '';
  slides.forEach((_, i) => {
    dotsContainer.insertAdjacentHTML(
      'beforeend',
      `<button class="dots__dot" data-slide=${i}></button>`
    );
  });
};

# 2. 激活 dot

切换 slide 时，需要同步 dot 的状态：

js 
const activeDot = function (index) {
  dots.forEach(dot => dot.classList.remove('dots__dot--active'));
  dots[index].classList.add('dots__dot--active');
};

# 3. 点击 dot 切换 slide

利用事件委托，避免给每个 dot 单独绑定监听器：

js 
dotsContainer.addEventListener('click', function (e) {
  if (!e.target.classList.contains('dots__dot')) return;
  const index = Number(e.target.dataset.slide);
  updateSlide(index);
});

# 4. 混用箭头、键盘、dot

如何避免冲突？

  • 箭头 / 键盘 → 修改 currentSlideIndex
  • dot 点击 → 直接根据 data-slide 跳转
  • 统一通过 updateSlide(index) 方法更新 slide 与 dot，从而保证状态一致。

# 七、整体运行逻辑

  1. 初始化：显示第一张，并生成对应 dots
  2. 用户交互：
    • 点击左右按钮
    • 使用键盘 ← / →
    • 点击 dot
  3. 调用 updateSlide(currentSlideIndex) 渲染 slide 与 dot

# 八、效果与扩展

这样一个轮播图就完成了，它的特点是：

  • 结构清晰，逻辑简单
  • 支持多种交互（按钮、键盘、dots）
  • 易于扩展，比如增加 自动播放、滑动手势 等功能
