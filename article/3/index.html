# 一、什么是映射表？

映射表（Mapping Table） 是一种使用对象或 Map 结构存储键值对关系的数据组织方式。它将条件判断转化为数据查询，实现数据驱动的编程范式。

# 传统方式 vs 映射表

# ❌ 传统 Switch 方式

javascript 
function getSeasonClassName(season) {
  switch (season) {
    case "春":
      return "seasons__spring";
    case "夏":
      return "seasons__summer";
    case "秋":
      return "seasons__autumn";
    case "冬":
      return "seasons__winter";
    default:
      return "";
  }
}

问题：

  • 代码冗长，重复性高
  • 添加新季节需要修改函数逻辑
  • 难以测试和维护

# ✅ 映射表方式

javascript 
const SEASON_CONFIG = {
  春: { className: "seasons__spring", label: "春天" },
  夏: { className: "seasons__summer", label: "夏天" },
  秋: { className: "seasons__autumn", label: "秋天" },
  冬: { className: "seasons__winter", label: "冬天" }
};

function getSeasonClassName(season) {
  return SEASON_CONFIG[season]?.className || "";
}

优势：

  • ✨ 代码简洁，一目了然
  • 🔧 易于扩展，只需添加数据
  • 📦 数据与逻辑分离
  • 🧪 方便单元测试

# 二、Object.values() 详解

# 基本语法

javascript 
Object.values(obj)

功能：返回一个包含对象所有可枚举属性值的数组。

# 特性说明

特性 说明
返回值 数组，包含对象自身的可枚举属性值
顺序 按照属性定义的顺序排列
原型链 不包含原型链上的属性
Symbol 属性 不包含 Symbol 类型的键

# 使用示例

javascript 
const user = {
  name: "张三",
  age: 25,
  city: "北京"
};

// 基础用法
console.log(Object.values(user));
// 输出: ["张三", 25, "北京"]

// 结合数组方法
const ages = Object.values({ tom: 20, jerry: 18, spike: 22 });
const averageAge = ages.reduce((sum, age) => sum + age, 0) / ages.length;
console.log(averageAge); // 20

# 实战：批量移除 CSS 类名

javascript 
const SEASON_CONFIG = {
  春: { className: "seasons__spring" },
  夏: { className: "seasons__summer" },
  秋: { className: "seasons__autumn" },
  冬: { className: "seasons__winter" }
};

// 提取所有 className
const allClassNames = Object.values(SEASON_CONFIG).map(config => config.className);
// ["seasons__spring", "seasons__summer", "seasons__autumn", "seasons__winter"]

// 批量移除类名
function removeAllSeasonClasses(element) {
  Object.values(SEASON_CONFIG).forEach(({ className }) => {
    element.classList.remove(className);
  });
}

# 三、Object.values() vs 扩展运算符 […]

# 核心区别

对比项 Object.values() […扩展运算符]
作用对象 对象（Object） 可迭代对象（Array、String、Set 等）
提取内容 对象的属性值 数组/可迭代对象的元素
返回类型 新数组 新数组（或展开后的元素）
典型场景 提取对象值集合 数组拷贝、合并

# 对比示例

# 示例 1：处理对象

javascript 
const SEASON_CONFIG = {
  春: { className: "seasons__spring" },
  夏: { className: "seasons__summer" }
};

// ✅ Object.values() - 提取对象的值
const values = Object.values(SEASON_CONFIG);
console.log(values);
// [{ className: "seasons__spring" }, { className: "seasons__summer" }]

// ❌ 扩展运算符 - 对象不可迭代（会报错）
// const values = [...SEASON_CONFIG]; // TypeError: SEASON_CONFIG is not iterable

// ✅ 但可以配合 Object.keys() 或 Object.entries()
const keys = [...Object.keys(SEASON_CONFIG)]; // ["春", "夏"]

# 示例 2：处理数组

javascript 
const colors = ["red", "green", "blue"];

// ✅ 扩展运算符 - 复制数组
const colorsCopy1 = [...colors];
console.log(colorsCopy1); // ["red", "green", "blue"]

// ✅ Object.values() - 也可以用于数组（数组是特殊对象）
const colorsCopy2 = Object.values(colors);
console.log(colorsCopy2); // ["red", "green", "blue"]

// 但语义不同：扩展运算符更符合数组拷贝的语义

# 在季节模块中的实际应用

javascript 
// 场景 1：移除所有季节类名
// 使用 Object.values() 提取配置对象中的所有值
Object.values(SEASON_CONFIG).forEach(({ className }) => {
  element.classList.remove(className);
});

// 场景 2：如果配置是数组形式
const SEASON_CLASSES = [
  "seasons__spring",
  "seasons__summer",
  "seasons__autumn",
  "seasons__winter"
];

// 使用扩展运算符进行操作
element.classList.remove(...SEASON_CLASSES); // 展开数组作为多个参数

# 选择建议

javascript 
// ✅ 推荐：从对象提取值时使用 Object.values()
const classNames = Object.values(SEASON_CONFIG).map(c => c.className);

// ✅ 推荐：复制/合并数组时使用扩展运算符
const allColors = [...primaryColors, ...secondaryColors];

// ✅ 推荐：函数参数展开时使用扩展运算符
Math.max(...numbers);
element.classList.add(...classList);

# 四、映射表的最佳实践

# 1. 使用常量命名

javascript 
// ✅ 好的做法：大写常量
const STATUS_CONFIG = {
  pending: { text: "待处理", color: "orange" },
  success: { text: "成功", color: "green" }
};

// ❌ 避免：普通变量命名
const statusConfig = { /* ... */ };

# 2. 添加类型安全（TypeScript）

typescript 
interface SeasonConfig {
  className: string;
  label: string;
  icon?: string;
}

const SEASON_CONFIG: Record<string, SeasonConfig> = {
  春: { className: "seasons__spring", label: "春天" }
};

# 3. 提供默认值

javascript 
function getSeasonConfig(season) {
  const defaultConfig = { className: "", label: "未知" };
  return SEASON_CONFIG[season] || defaultConfig;
}

# 4. 使用 Map 处理复杂场景

javascript 
// 当键不是字符串时，使用 Map
const RESPONSE_HANDLER = new Map([
  [200, () => console.log("成功")],
  [404, () => console.log("未找到")],
  [500, () => console.log("服务器错误")]
]);

// 执行对应处理函数
const handler = RESPONSE_HANDLER.get(statusCode);
handler?.();
