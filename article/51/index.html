记录前端实习中常用的 git 操作

# 本地同步远程分支

新一期需求通常会创建新的远程分支，此时需要在本地创建对应分支并与其关联

cmd 
// -------------------本地同步远程分支-------------------
git branch -a # 查看远程分支
git checkout -b dev-0.1.0 origin/dev-0.1.0 # 本地创建分支 0.1.0 并关联到远程分支

# 提交流程

提交前，先使用 stash 暂存本地修改，再拉取最新代码，最后恢复修改。即使发生冲突，本地修改和远程代码也会保留，便于后续处理

cmd 
// -------------------提交流程-------------------
# 1. 暂存当前修改
git stash save "执行存储时，添加备注，方便查找"

# 2. 拉取最新代码
git pull

# 3. 恢复自己的修改
git stash pop

# 4. 解决可能的冲突后提交
git add .
git commit -m "feat: XXX需求开发"
git push origin main

# stash 暂存单个文件

cmd 
// -------------------stash 暂存单个文件-------------------
git stash push -m "描述信息" -- 文件路径

# 示例
git stash push -m "暂存 analysis.vue 文件" -- src/views/analysis.vue

# 查看 stash 列表
git stash list

# 恢复最近一次 stash
git stash pop
