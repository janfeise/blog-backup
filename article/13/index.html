# JavaScript 中的 this 绑定机制详解

this 是 JavaScript 中一个非常关键却又容易让人困惑的概念 它的指向不仅依赖于函数的定义方式，还取决于函数的调用方式 本文将带你系统梳理 this 的绑定规则及其手动绑定方式，帮助你真正掌握它的用法

# 一、默认情况下的 this 指向规则

# 1. 普通函数：谁调用 this 指向谁

在没有手动绑定的情况下，普通函数中的 this 指向调用该函数的对象：

js 
function show() {
  console.log(this.name);
}

const obj = { name: 'Alice', show };
obj.show(); // 输出：Alice

在上面的例子中，obj.show() 实际上是由 obj 调用的，因此 this 指向 obj

如果是直接调用函数（如 show()），在非严格模式下，this 会默认指向全局对象 window；在严格模式下，则为 undefined

# 2. 箭头函数：没有自己的 this

箭头函数不绑定自己的 this，它的 this 始终继承自定义时所在的作用域（词法作用域）：

在js中，作用域只有：函数和模块，对象并不是作用域

js 
const obj = {
  name: 'Bob',
  show: () => {
    console.log(this.name);
  }
};

obj.show(); // 输出：undefined（this继承于外层作用域，而不是obj）

在这个例子中，箭头函数的 this 并没有指向 obj，而是来自它定义时的上下文——通常是 window 或 undefined（在严格模式下）

# 二、手动设置 this 的三种方式

在 JavaScript 中，我们可以通过 call、apply、bind 三个方法来手动指定函数的 this 指向

# 1. call() 和 apply()

这两个方法的主要作用是立即调用函数，并设置 this：

js 
/**
* this 的默认行为
普通函数调用时（非严格模式下），this 默认指向全局对象（浏览器中是 window，Node.js 中是 global）。
所以函数 greet('Hello') 单独调用时，this.name 会是 undefined。
*/
function greet(greeting) {
  console.log(`${greeting}, ${this.name}`);
}

const person = { name: 'Charlie' };

// call：第一个参数是this绑定的对象，后面依次是函数需要的参数
greet.call(person, 'Hello');  
// 输出: Hello, Charlie

// apply：第一个参数同样是this绑定的对象，第二个参数是参数数组
greet.apply(person, ['Hi']);  
// 输出: Hi, Charlie
  • call() 接收参数列表
  • apply() 接收参数数组

它们都会立即执行目标函数

# 2. bind()

与 call 和 apply 不同，bind() 并不会立即执行函数，而是返回一个新的函数，这个新函数内部的 this 被永久绑定为指定的对象：

js 
function greet() {
  console.log(this.name);
}

const person = { name: 'David' };

const boundGreet = greet.bind(person);
boundGreet();  // David

这意味着你可以将绑定好的函数重复使用，比如在事件监听中就非常常见：

js 
const btn = document.querySelector('button');
btn.addEventListener('click', boundGreet); // 正确方式

在事件绑定中使用 call 或 apply 是不合适的，因为它们会立即执行函数，而 bind 返回的是一个可复用的函数对象，正好满足需求

# 三、bind() 的额外功能：预设参数

除了绑定 this，bind() 还可以预设部分参数，形成“函数柯里化”的效果：

js 
function multiply(a, b) {
  return a * b;
}

const double = multiply.bind(null, 2); // null表示不绑定this指向
console.log(double(5)); // 输出：10

注意：通过 bind 预设参数不会改变原函数 multiply，而是返回了一个新的函数 double

这种用法在实际开发中非常灵活，尤其在事件处理或函数节流、防抖中非常常见

# 总结

方法 是否立即执行 是否绑定 this 是否支持预设参数
call ✅ 是 ✅ 是 ❌ 否
apply ✅ 是 ✅ 是 ❌ 否
bind ❌ 否 ✅ 是 ✅ 是

掌握好 this 的指向和绑定方式，将能帮助你更好地理解 JavaScript 中函数的执行机制，也能避免许多常见的错误
