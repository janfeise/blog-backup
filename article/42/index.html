Echarts 图表组成结构

2026.07.04 发布 45 分钟阅读 更新于 2026.10.02

知道有什么，才能更好的命令 AI 生成想要的图

# 标题 title

在 echarts 中，title有两个：title和subtitle，如上图的用户增长趋势为title，下方的2025年数据为subtitle

js 
var option = {
            // 1. 标题 (title)
            title: {
                text: '用户增长趋势',
                subtext: '2025年数据'
            }
}

# 系列 series

在 Echarts 中 系列 series 是核心概念，series 定义了 图表中的“数据 + 如何绘制这些数据”，“系列”决定了数据画出来长什么样。一个图表可以包含一个或多个系列

txt 
销量

300 |        █
200 |    █   █
100 | █  █   █
    ----------------
      A  B   C

上图中绘制的阴影，便是通过系列控制的

js 
option = {
    title: {
        text: '用户增长趋势'
    },

    xAxis: {
        data: ['周一', '周二', '周三']
    },

    yAxis: {},

    series: [
        {
            name: '新增用户',
            type: 'line',
            data: [100, 200, 300]
        }
    ]
}

其中：

js 
series: [
    {
        name: '新增用户',
        type: 'line',
        data: [100, 200, 300]
    }
]

就是一个系列（可添加多个系列，最终绘制的图表便是多条数据的集合）

它表示：

属性 含义
name 系列名称
type 图表类型
data 数据
其他配置 颜色、样式、动画等

# 图例 legend

图例组件展现了不同系列的标记(symbol)，颜色和名字，也就是说，图例表示图中的几条数据分别是什么，蓝色的线是活跃用户？绿色的线是新增用户？对系列的一个说明。可以通过点击图例控制哪些系列不显示

js 
legend: {
    data: ['新增用户', '活跃用户']
}

# 提示框 tooltip

悬浮在图中的数据点时，所出现的悬浮框便是 Echarts 的提示框，用于为用户呈现这里的数据表示什么

js 
tooltip: {
    trigger: 'axis'
}

# tooltip. trigger

触发类型

可选：

  • 'item'

    数据项图形触发，主要在散点图，饼图等无类目轴的图表中使用

  • 'axis'

    坐标轴触发，主要在柱状图，折线图等会使用类目轴的图表中使用

  • 'none'

    什么都不触发

# 网格 grid

在 echarts 中图是默认占据所指定的整块空间的，要想在图周围显示：visualmap、datazoom等，需通过grid留出空间

js 
grid: {
    left: '5%',
    right: '15%', // 给 visualMap 留出空间
    bottom: '15%' // 给 dataZoom 留出空间
}

# Y轴与X轴

在echarts中轴分 X 轴 (xAxis) 和 Y 轴 (yAxis)，可通过 type 属性来决定轴展示什么类型的数据。

  • type: 'category'（类目轴）：最常用。适用于字符串标签（如：周一、周二；苹果、香蕉）。
    • 用法：数据是文本，轴上的刻度由这些文本决定。
  • type: 'value'（数值轴）：最常用。适用于连续的数字（如：价格、销量、温度）。
    • 用法：数据是数字，轴会自动计算最小值和最大值以及刻度间隔。
  • type: 'time'（时间轴）：专门用于展示日期/时间。它会自动根据时间跨度切换到“年、月、日、时”等合适的粒度。
  • type: 'log'（对数轴）：用于数据跨度极大的情况（如：从 10 到 100000，通常用对数坐标防止小数据被压缩掉）。

💡 经典组合：xAxis 用 'category'（横轴是日期/名称），yAxis 用 'value'（纵轴是具体的数值），这是折线图和柱状图 90% 的情况。

# 标记线 markLine 与 标记点 markPoint

# 标记线

标记线用来在图表中绘制一条贯穿整个绘图区的水平线或垂直线，起到参考、警示、对比的作用，如：

  • 标记平均值（一条直线贯穿整个区域）

  • 标记最大值与最小值

  • 设置目标警戒线/阈值线（业务标杆）

js 
series: [{
    type: 'line',
    data: [100, 200, 150, 300],
    markLine: {
        data: [
            { type: 'average', name: '平均值' }
        ],
        lineStyle: { type: 'dashed', color: 'orange' } // 设为橙色虚线
    }
}]

# 标记点

标注某个数据点本身（比如最高点），用 markPoint (标记点)

js 
// 标记点 (markPoint) - 标注最大值
markPoint: {
  data: [{ type: "max", name: "最大值" }],
  symbol: "pin",
  symbolSize: 50,
}

# 数据集 dataset

ECharts 本身不支持将 dataset 作为一个“可视化的数据表格”渲染在图表周围或页面上，dataset的作用是： “数据管理与视图解耦”，系列 series 不用定义数据，可直接使用dataset的数据，对数据统一管理

1. 传统写法
你必须明确告诉 series，它的数据是什么：

js 
// 手动把数据写进每个系列里
series: [
  { type: 'bar', data: [41.1, 30.4, 65.1, 53.3] },
  { type: 'bar', data: [86.5, 92.1, 85.7, 83.1] }
]

2. 使用 dataset 的写法（自动映射）
你把所有数据提到最前面，然后 series 保持空置（或者只写类型和名字）：

js 
dataset: {
  source: [
    [41.1, 30.4, 65.1, 53.3], // 第 1 行数据
    [86.5, 92.1, 85.7, 83.1]  // 第 2 行数据
  ]
},
series: [
  { type: 'bar' }, // 第一个系列，自动抓取第 1 行数据
  { type: 'bar' }  // 第二个系列，自动抓取第 2 行数据
]

通过 dataset 实现了数据与视图的解耦，数据统一管理，系列 series 只处理视图的绘制，无需将数据进行拆分

# 工具栏 toolbox

工具栏。内置有导出图片，数据视图，动态类型切换，数据区域缩放，重置五个工具

js 
// 2. 工具栏 (toolbox) - 下载、缩放、重置
toolbox: {
    feature: {
        saveAsImage: {},
        dataZoom: { yAxisIndex: 'none' },
        restore: {}
    }
}

# 标记区域 markArea

series-line.markArea，用于对系列中某块区域进行标记

上图中的蓝色背景区域，图表标域，常用于标记图表中某个范围的数据，例如标出某段时间投放了广告

如下图：将周二到周三区域进行标记，背景色为浅蓝色

js 
series: [
            {
                name: '新增用户',
                type: 'line',
                smooth: true
            },
            {
                name: '活跃用户',
                type: 'line',
                smooth: true,
                // 12. 标记点 (markPoint) - 标注最大值
                markPoint: {
                    data: [{ type: 'max', name: '最大值' }],
                    symbol: 'pin',
                    symbolSize: 50
                },
                // 13. 标记线 (markLine) - 标注平均线
                markLine: {
                    data: [{ type: 'average', name: '平均值' }],
                    lineStyle: { type: 'dashed', color: 'orange' }
                },
                // 14. 标记区域 (markArea) - 标注区域
                markArea: {
                    data: [
                        [{ xAxis: '周二' }, { xAxis: '周三' }]
                    ],
                    itemStyle: { color: 'rgba(0, 100, 255, 0.1)' }
                }
            }
        ]

# 视觉映射 visualMap

将数据映射到视觉元素（视觉通道）

js 
// 6. 视觉映射 (visualMap) - 将数值映射到颜色（右侧颜色条）
visualMap: {
    type: 'continuous',
    min: 0,
    max: 1000,
    right: 10,
    top: 'middle',
    calculable: true,
    inRange: { color: ['#4db3ff', '#00e5ff', '#ff3333'] }
}

# 数据缩放 dataZoom

dataZoom 组件 用于区域缩放，从而能自由关注细节的数据信息，或者概览数据整体，或者去除离群点的影响

js 
// 7. 数据缩放 (dataZoom) - 底部滑动条
dataZoom: [
    { type: 'slider', start: 0, end: 100 }
]

# 示例 html demo

将下面的代码保存为html文件，可直接打开，并显示图表

html 
<!doctype html>
<html lang="zh-CN">
  <head>
    <meta charset="UTF-8" />
    <title>ECharts 图表组成结构实现</title>
    <!-- 引入 ECharts -->
    <script src="https://cdn.jsdelivr.net/npm/echarts@5/dist/echarts.min.js"></script>
  </head>
  <body>
    <!-- 准备一个具备大小的 DOM 容器 -->
    <div id="main" style="width: 800px; height: 500px"></div>

    <script>
      var myChart = echarts.init(document.getElementById("main"));

      var option = {
        // 1. 标题 (title)
        title: {
          text: "用户增长趋势",
          subtext: "2025年数据",
        },
        // 2. 工具栏 (toolbox) - 下载、缩放、重置
        toolbox: {
          feature: {
            saveAsImage: {},
            dataZoom: { yAxisIndex: "none" },
            restore: {},
          },
        },
        // 3. 提示框 (tooltip) - 鼠标悬停时显示
        tooltip: {
          trigger: "axis",
        },
        // 4. 图例 (legend)
        legend: {
          data: ["新增用户", "活跃用户"],
        },
        // 5. 数据集 (dataset) - 核心数据源，使用表格形式
        dataset: {
          dimensions: ["日期", "新增用户", "活跃用户"],
          source: [
            { 日期: "周一", 新增用户: 80, 活跃用户: 300 },
            { 日期: "周二", 新增用户: 150, 活跃用户: 400 },
            { 日期: "周三", 新增用户: 200, 活跃用户: 700 },
          ],
        },
        // 6. 视觉映射 (visualMap) - 映射数值到颜色（右侧颜色条）
        visualMap: {
          type: "continuous",
          min: 0,
          max: 1000,
          right: 10,
          top: "middle",
          calculable: true,
          inRange: { color: ["#4db3ff", "#00e5ff", "#ff3333"] },
        },
        // 7. 数据缩放 (dataZoom) - 底部滑动条
        dataZoom: [{ type: "slider", start: 0, end: 100 }],
        // 8. 网格 (grid) - 绘图区域布局
        grid: {
          left: "5%",
          right: "15%", // 给 visualMap 留出空间
          bottom: "15%", // 给 dataZoom 留出空间
        },
        // 9. X轴 (xAxis) & 10. Y轴 (yAxis)
        xAxis: { type: "category" },
        yAxis: { type: "value" },

        // 11. 系列 (series: line) - 设置折线图
        series: [
          {
            name: "新增用户",
            type: "line",
            smooth: true,
          },
          {
            name: "活跃用户",
            type: "line",
            smooth: true,
            // 12. 标记点 (markPoint) - 标注最大值
            markPoint: {
              data: [{ type: "max", name: "最大值" }],
              symbol: "pin",
              symbolSize: 50,
            },
            // 13. 标记线 (markLine) - 标注平均线
            markLine: {
              data: [{ type: "average", name: "平均值" }],
              lineStyle: { type: "dashed", color: "orange" },
            },
            // 14. 标记区域 (markArea) - 标注区域
            markArea: {
              data: [[{ xAxis: "周二" }, { xAxis: "周三" }]],
              itemStyle: { color: "rgba(0, 100, 255, 0.1)" },
            },
          },
        ],
      };

      myChart.setOption(option);
    </script>
  </body>
</html>
