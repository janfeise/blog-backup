# 数据库迁移

在 1panel 面板中安装 phpAdmin，MySQL的图形化网站

  1. 打开 phpAdmin 网站
  2. 创建数据库，如：tilex_blog，规则选择 utf8mb4_general_ci
  3. 导入表，如：posts.sql
  4. 检查

# 后端springboot迁移

准备两个文件：

  1. application.properties：配置文件
  2. jar 包

注意配置文件需更改为实际的 MySQL 运行环境：

  1. MySQL 容器名 + 实际端口
  2. MySQL root 密码

如：将下面示例的 【】替换为实际的数据

properties 
spring.datasource.driver-class-name=com.mysql.cj.jdbc.Driver
spring.datasource.url=jdbc:mysql://【1Panel-mysql-XXXXXXX:3306】/tilex_blog?useUnicode=true&characterEncoding=utf8&useSSL=false&serverTimezone=UTC
spring.datasource.username=root
spring.datasource.password=【XXXXXXXX】

若后端启动失败，查看日志，将日志发给AI分析即可

验证：后端启动成功后，尝试 ip + 端口访问后端api，若api返回成功，则说明后端运行成功

# 前端

反向代理 + 配置前端路由重定向

在配置文件需添加：

text 
location / {
    try_files $uri $uri/ /index.html; 
}

进行前端路由重定向配置，保存并重载 OpenResty 后，访问博客的其他页面，如 https://www.tilex.world/article/64， 才能正常打开

# remake42

评论区分为两部分：remark42容器 + 反向代理

remark42 容器：进入 docker-compose.yml 所在目录，执行启动命令：

cmd 
docker compose up -d
cmd 
# 重启
docker compose restart

# 停止并删除容器，但保留 ./var 数据
docker compose down

# 拉取新镜像并重新启动
docker compose pull
docker compose up -d
