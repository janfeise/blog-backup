dotenv-node.js 读取 env 数据

2026.08.08 发布 3 分钟阅读 更新于 2026.10.02

在 node.js 中，不支持直接读取 env 文件数据，与前端不同，前端在 vite 的加持下可读取 env 数据，但 node.js 需 dotenv 模块才能加载 env 数据

js 
import dotenv from 'dotenv'; 

dotenv.config();

console.log(process.env.DEEPSEEK_API_KEY);

dotenv.config()读取 env 文件，并进行解析

  1. 读取 .env 文件（文本）
  2. 将 env 中的数据解析成 key-value 形式
  3. 写入 process.env （process：进程）

完成后会挂载到 process.env 上：

js 
process.env.PORT = "3000"
process.env.DB_HOST = "localhost"

process 是什么？——进程，进程是操作系统分配资源的最小单位。 Node.js 把这个操作系统进程封装成了一个全局对象——process

dotenv 把 .env 文件的内容读出来，挂载到 process.env 对象上，之后便可以通过代码访问 env 文件中的数据了
