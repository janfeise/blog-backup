# Vue 自定义 Hooks：让组件逻辑与 UI 解耦

在 Vue 开发中，一个组件通常由两部分组成：

  • UI：页面结构与展示
  • 状态与逻辑：数据管理、事件处理、生命周期逻辑等

当组件较为简单时，通常会将这两部分直接写在同一个组件中。但随着业务复杂度提升，会逐渐出现以下问题：

  • 组件代码越来越长
  • 状态逻辑难以维护
  • 多个组件存在重复逻辑
  • UI 与业务逻辑强耦合

此时，自定义 Hooks 便成为了一个非常重要的解决方案。

# 什么是 Vue 自定义 Hooks

Vue 自定义 Hooks 本质上是：

  • 将组件中的状态与逻辑抽离到独立函数中
  • 通过组合式 API 实现<u>逻辑复用</u>
  • UI 组件只负责展示
  • Hooks 负责<u>管理状态与行为</u>

这种模式本质上是一种“逻辑复用”和“职责拆分”的思想。

如下图所示：

组件不再同时负责 UI 与逻辑，而是：

  • UI 专注页面展示
  • Hooks 专注状态与逻辑管理

从而实现真正意义上的解耦。

# 示例：计数器

计数器较为简单，一般无需拆分为UI和自定义hooks，但是作为自定义hooks的学习却是不错的例子

计数器:

  • UI 负责展示 count
  • Hooks 负责管理状态与逻辑处理

自定义hooks：

js 
export const useCount = () => {
  const count = ref(0);

  const increase = (num = 0) => {
    count.value += num;
  }

  onMounted(() => {
    count.value = 0; // 初始化
  })

  return {
    count,
    increase
  }
}

这个 Hooks 中包含：

  • 状态：count
  • 方法：increase
  • 生命周期逻辑：onMounted

并最终通过 return 暴露出去。

UI：

vue 
<script setup>
const {count, increase} = useCount();
</script>

<template>
  <p>{{count}}</p>
  <button @click="increase(1)">+1</button><br/>
  <button @click="increase(10)">+10</button>
</template>

一个简单的计数器便完成了，通过这个例子可以看到，此时组件会变得非常清晰

组件本身只关心：

  • count 如何展示
  • 点击按钮时调用什么函数

至于：

  • count 如何维护
  • increase 如何实现
  • 生命周期如何处理

这些全部由 Hooks 负责，但在实际开发中并不是将状态全部由 hooks 管理，只有复用的状态与逻辑才写入hooks，其它的状态和逻辑处理由组件自身维护，若将所有状态和逻辑写入hooks，只不过是换了个地方，没必要，只有可复用逻辑才进行抽离

# useVue

useVue是基于 Vue3 Composition API 封装了大量可复用 Hooks

提供了大量现成 Hooks，例如：

  • 鼠标位置监听
  • 本地存储
  • 请求状态
  • 防抖节流
  • 浏览器 API
  • 设备信息
  • 生命周期增强
  • 动画
  • 时间处理

开发者无需重复造轮子。
