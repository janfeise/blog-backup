# 使用 marked 与 highlight.js 渲染 Markdown（含代码高亮与表格美化）

一级主题 二级主题 三级主题示例
marked 简介 Markdown → HTML 渲染 不支持代码高亮、表格样式缺失
安装依赖 npm 安装 marked、highlight.js
样式准备 引入 hljs 样式 & 表格样式 自定义代码与表格的视觉效果
配置 marked 设置选项 自定义 highlight 函数
内容渲染 前端集成流程 高亮代码块、美化表格

在前端开发中，如果希望在网页上展示 Markdown 格式的内容，marked 搭配 highlight.js 是最常用的组合方案：

  • marked：将 Markdown 文本解析为 HTML 代码
  • highlight.js：为代码块添加语法高亮

这套方案不仅适用于博客系统，还常用于文档平台、知识库、在线 Markdown 编辑器等场景本文将从零搭建完整的 Markdown 渲染流程，并解决常见问题：

  • 代码块未高亮
  • 表格样式过于简陋

# 一、项目整体流程

完整使用流程如下：

  1. 安装依赖：引入 marked 和 highlight.js
  2. 准备样式：添加代码高亮主题和表格样式
  3. 配置 marked：集成 highlight.js 的高亮逻辑
  4. 渲染 Markdown：在前端解析、渲染并高亮内容

# 1. marked 简介：轻量级 Markdown 解析器

marked 是一款快速、轻量的 Markdown 转 HTML 工具，支持：

  • 标题（#、##）
  • 引用（>）
  • 列表（-、1.）
  • 代码块（`````）
  • 表格（|）

⚠️ 需要注意两点：

  1. 代码块不自带语法高亮，需与 highlight.js 配合
  2. 表格无默认样式，需手动编写 CSS 美化

# 2. 安装依赖

使用 npm 安装核心模块：

bash 
npm install marked highlight.js

# 3. 准备样式：代码高亮 + 表格样式

# （1）引入代码高亮主题

在 node_modules/highlight.js/styles/ 中选择一个主题（如 github.css），复制到项目的 css/ 目录，并在 HTML 中引入：

html 
<link rel="stylesheet" href="./css/github.css" />

✅ 说明：highlight.js 仅生成带有类名的 HTML，实际的颜色和样式由 CSS 控制

# （2）自定义表格样式

由于 marked 输出的表格是原生 <table>，我们需要自定义 CSS 来提升视觉效果：

css 
.post__content table {
  width: 100%;
  border-collapse: collapse;
  margin: 1em 0;
  font-size: 14px;
}

.post__content th,
.post__content td {
  border: 1px solid #ccc;
  padding: 8px 12px;
  text-align: left;
}

.post__content th {
  background-color: #f5f5f5;
}

.post__content tr:nth-child(even) td {
  background-color: #fafafa;
}

# 4. 配置 marked（utils/markdown.js）

接下来，为 marked 配置选项并集成 highlight.js：

js 
// utils/markdown.js
import { marked } from "../../node_modules/marked/lib/marked.esm";
import hljs from "highlight.js";

// 按需注册语言（可选）
import bash from "highlight.js/lib/languages/bash";
hljs.registerLanguage("bash", bash);

marked.setOptions({
  gfm: true,
  breaks: true,
  headerIds: true,
  highlight: (code, lang) => {
    if (lang && hljs.getLanguage(lang)) {
      return hljs.highlight(code, { language: lang }).value;
    }
    return hljs.highlightAuto(code).value;
  },
  langPrefix: "hljs language-",
});

export default marked;

# 5. 渲染 Markdown 内容（前端集成）

在前端项目中使用时，可以这样渲染 Markdown 并应用高亮：

js 
import marked from "../utils/markdown.js";
import hljs from "highlight.js";

// 假设 markdownContent 为后端返回的 Markdown 字符串
const markdownContent = `
# 示例标题

这是一个代码块：

\`\`\`bash
echo "Hello World"
\`\`\`

这是一个表格：

| 姓名 | 年龄 |
| ---- | ---- |
| 张三 | 20   |
| 李四 | 22   |
`;

// Markdown → HTML
const html = marked(markdownContent);

// 插入页面
const el = document.querySelector("#article");
el.innerHTML = html;

// 对所有代码块应用高亮
el.querySelectorAll("pre code").forEach((block) => {
  hljs.highlightElement(block);
});

📌 建议：在渲染后主动调用 highlightElement，以确保动态内容也能正确高亮

# 6. 最终效果与注意事项

通过上述流程，我们实现了完整的 Markdown 渲染功能：

功能 工具 说明
Markdown → HTML marked 不带代码高亮和表格样式
代码高亮 highlight.js 需引入对应 CSS 主题
表格样式美化 自定义 CSS 使用 .post__content table 等选择器
常规 Markdown 支持 marked 标题、列表、引用等默认支持

# 总结：结构 + 样式双升级

  • 结构化解析：marked 负责将 Markdown 转换为 HTML
  • 可读性提升：highlight.js 为代码块增加语法高亮
  • 视觉优化：自定义表格样式，让展示更专业

这套方案简单、稳定、易扩展，是前端开发中展示 Markdown 内容的最佳实践之一
