动态路由

阅读时间约 8 分钟 · 字数 1459

哔站是如何实现：点击某个视频时，跳转新页面，并显示该视频的相关内容的？显然不可能为每个视频编写对应的页面（后续上传的视频如何能编写对应的页面呢）

方法：建立一个 <u>通用</u> 的模版页面，将内容传递给模板，模板更新即为对应的详情页

# 核心问题

前端需要解决的核心问题是：如何用一个通用页面模板展示不同内容，并通过URL或路由参数加载对应数据？

问题可以拆解为三点：

  1. 页面模板复用 前端不能为每条内容都创建一个页面，因此需要一个通用模板页面。模板中可以包含标题、发布时间、正文内容、评论区等模块，通过传入不同的数据来渲染不同的内容。

  2. URL参数传递内容标识 用户点击列表项时，前端需要知道应该展示哪条内容。常见做法是通过 URL 传递内容标识：

    • Query 参数形式：article.html?id=1
    • Path 参数形式：article.html/1

    注意两者的差异：

    • article.html?id=1 页面不会真正导航到新的HTML页面，而是在同一个页面中通过JS解析参数加载内容。
    • article.html/1 可能触发前端路由机制导航到“新页面”，实现更直观的动态路由体验。

  3. 前端路由处理动态路径 现代前端框架（如 React、Vue）提供了路由机制，可以通过动态路径参数实现页面跳转：

    • React：/article/:id → 使用 useParams() 获取 id
    • Vue：/article/:id → 使用 route.params.id 获取 id

    然后在模板中根据参数请求对应数据（通过 API 或本地 JSON），动态渲染页面内容。

# 实现思路

  1. 建立通用模板页面 页面结构固定，只需一个 HTML 文件，例如 article.html。模板中使用占位符或前端组件渲染动态内容。

    html 
    <!-- article.html -->
<div>
    通用模版编写
</div>

  2. 通过 URL 获取参数

    前提紧要：点击视频等时会自动跳转，且URL发生改变，如：/article/1

    • Query 参数：window.location.search
    • Path 参数：路由库提供的参数接口 useParams() / route.params

  3. 加载对应数据 根据参数调用 API 或读取本地数据，将内容填充到模板中。

  4. 渲染页面 将标题、正文、时间等动态内容插入页面。模板可复用，支持无限量新增内容，而无需新增HTML页面。

# 总结

动态路由的核心思想是 模板+参数+数据：

  • 模板：一个页面模板复用所有内容
  • 参数：通过 URL 或路由参数标识具体内容
  • 数据：根据参数获取对应内容并渲染

这种方式不仅节约开发成本，也方便后续内容扩展，网站可以随时添加新文章或视频而无需额外创建页面。URL形式的不同（?id=1 vs /1）只是实现细节的差异，但最终目标都是实现动态页面展示。
