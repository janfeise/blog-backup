常用快捷键梳理

2026.10.09 发布 27 分钟阅读 更新于 2026.10.09

梳理日常使用电脑时常用的快捷键，大致分为以下四部分：

  • 通用快捷键
  • bilibili
  • 浏览器
  • Windows 电脑

# 通用快捷键

快捷键 功能 说明
Ctrl + C 复制 Copy
Ctrl + V 粘贴 Paste
Ctrl + X 剪切 Cut
Ctrl + Z 撤销 Undo
Ctrl + A 全选 All
Ctrl + F 查找 Find，网页、文档、代码编辑器通用
Ctrl + S 保存 Save
Esc 取消 / 退出 关闭弹窗、退出当前状态等

# Bilibili 常用快捷键

快捷键 功能 说明
F 全屏 / 退出全屏 Fullscreen
D 开启 / 关闭弹幕 弹幕
[ 上一个视频 [ ]，系列 / 合集中的上一集
] 下一个视频 [ ]，系列 / 合集中的下一集
Space 空格 播放 / 暂停 视频网站最常用操作
← / → 后退 / 快进 快速调整播放进度
↑ / ↓ 增大 / 减小音量 视频播放控制

可惜没有找到重置视频进度的快捷键，每次用鼠标拖动进度条到视频开头，还是有点繁琐

# 浏览器常用快捷键

快捷键 功能 说明
Ctrl + T 新建标签页 Tab
Ctrl + W 关闭当前标签页 与 Ctrl + T 对应
Ctrl + Shift + T 恢复刚关闭的标签页 非常实用，可连续恢复多个
Ctrl + L 聚焦地址栏，好用🤩 Location，可直接输入 URL 或搜索内容
Ctrl + Tab 切换到下一个标签页 标签页之间快速切换
Ctrl + Shift + Tab 切换到上一个标签页 与 Ctrl + Tab 对应
Ctrl + 1 ~ 8 切换到指定标签页 Ctrl + 1 = 第一个标签页
Ctrl + 9 切换到最后一个标签页 标签很多时很好用
Ctrl + R 刷新网页 Reload
Ctrl + Shift + R 强制刷新 通常会忽略部分缓存，前端开发常用
Ctrl + D 收藏当前网页 添加书签
Ctrl + F 页面内查找 Find
Ctrl + U 查看网页源代码 前端开发常用，可判断网站是否是SPA
Ctrl + shift + C 打开开发者工具 check，不太习惯 F12
Ctrl + N 新建窗口 Chrome / Edge 常用
Ctrl + Shift + N 新建无痕窗口 Chrome / Edge 常用

# Windows 窗口与软件管理

快捷键 功能 说明
Alt + Tab 切换软件 在打开的软件之间切换
Ctrl + Alt + Tab 固定任务切换界面 可松开按键后继续选择窗口，常与Ctrl + W搭配使用，快速关闭软件
Ctrl + W 关闭 与 Ctrl + Alt + Tab 搭配使用
Win + D 显示 / 恢复桌面 Desktop，常用
Win + ↑ 最大化当前窗口 窗口布局
Win + ↓ 还原 / 最小化窗口 与 Win + ↑ 对应
Win + ← 窗口贴靠左侧 分屏非常好用
Win + → 窗口贴靠右侧 分屏非常好用

# Windows 系统功能

快捷键 功能 说明
Win + E 打开文件资源管理器 Explorer
Win + R 打开“运行”，可输入：calc（计算器）、cmd（终端）…… Run
Win + I 打开 Windows 设置，调整耳机蓝牙时好用 Settings
Win + S Windows 搜索，快速打开软件 Search
Win + V 打开剪贴板历史 强烈推荐开启
Win + L 锁屏，锁定电脑 Lock
Ctrl + Shift + Esc 打开任务管理器 比 Ctrl + Alt + Delete 更直接
Win + X 打开高级系统菜单 可继续通过字母执行操作
Win + X → U → U 关机，好用🤩 快速关机
Win + X → U → R 重启 与关机操作同一套逻辑
