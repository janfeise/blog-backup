# 视口、页面、屏幕

视口、页面、屏幕==都以左上角==为坐标原点

屏幕：即显示器

页面：整个HTML文档，即整个HTML的所有内容

视口：浏览器窗口，也叫client

页面高度 3000px，但视口(浏览器窗口）高度只有 600px

# 坐标系统

# 视口 (viewport) — 浏览器可见区域

  • clientX / clientY
    • 相对于**浏览器可视区域(视口)**左上角 (0,0) 的坐标。
    • 不管页面有没有滚动，始终以当前可见区域为参考点。
    • 举例：
      • 视口宽 800px，高 600px。
      • 鼠标在屏幕右下角 → clientX=800，clientY=600。
      • 页面上下滚动不影响这个值。

# 页面 (page/document) — 整个网页文档

  • pageX / pageY
    • 相对于页面整体左上角 (0,0) 的坐标。
    • 会随滚动条偏移而改变。
    • 举例：
      • 页面高度 3000px，但视口只有 600px。
      • 滚动到页面 400px 的位置，鼠标在视口顶部。
      • 这时 clientY=0，而 pageY=400。

# 屏幕 (screen/显示器) — 物理显示器

  • screenX / screenY
    • 相对于显示器屏幕左上角 (0,0) 的坐标。
    • 和浏览器窗口、页面滚动无关。
    • 举例：
      • 如果你的浏览器窗口放在屏幕中间，那么鼠标点击网页左上角时：
        • clientX=0，pageX=0，但 screenX 可能=200（因为窗口距离屏幕左边有 200px）。

# 元素内偏移 (offset) — 针对某个元素

  • offsetX / offsetY
    • 相对于事件目标元素（target element）左上角 (0,0) 的坐标。
    • 用来确定鼠标在某个元素内部的位置。
    • 举例：
      • 一个 div 宽 300px，高 100px。
      • 鼠标点在该 div 的左上角：offsetX=0, offsetY=0。
      • 鼠标点在 div 的右下角：offsetX=300, offsetY=100。

# ==坐标计算==

在前端开发中，我们经常需要知道鼠标点击位置、元素在页面中的位置，以及如何在视口、页面、屏幕三个维度上进行坐标换算。常见的获取方式主要有两种：

  1. ==事件对象（Event Object）== 在事件监听中直接读取属性（如 clientX、pageX、screenX 等）
  2. ==DOM 元素方法== 使用 getBoundingClientRect() 获取元素在视口中的位置，再结合滚动值或窗口位置推算页面/屏幕坐标

# 事件对象

事件对象在监听事件（如 click、mousemove）时，==可直接获取==多个坐标维度：

# 1. 视口坐标（clientX / clientY）

  • 定义：相对于浏览器 视口左上角 的坐标，不会随页面滚动改变。
  • 示例：
js 
element.addEventListener("click", function (e) {
  console.log("视口坐标：", e.clientX, e.clientY);
});
  • 应用场景：定位浮动元素（如弹窗、tooltip）在当前可视窗口中的位置。

# 2. 页面坐标（pageX / pageY）

  • 定义：相对于整个 文档页面左上角 的坐标，会随滚动改变。
  • 示例：
js 
element.addEventListener("click", function (e) {
  console.log("页面坐标：", e.pageX, e.pageY);
});
  • 换算关系：
js 
e.pageX = e.clientX + window.scrollX;
e.pageY = e.clientY + window.scrollY;
  • 应用场景：拖拽操作，让元素在整个页面中随鼠标移动。

# 3. 屏幕坐标（screenX / screenY）

  • 定义：相对于 用户屏幕左上角 的坐标，受分辨率和缩放影响。
  • 示例：
js 
element.addEventListener("click", function (e) {
  console.log("屏幕坐标：", e.screenX, e.screenY);
});
  • 应用场景：
    • 多窗口通信
    • 跨屏交互（如窗口间位置同步）

# ==getBoundingClientRect==

如果需要==获取 DOM 元素 在页面中的位置==，就要借助 getBoundingClientRect(), 其中getBoundingClientRect返回的是==视口坐标==

window.scrollY 返回的是 当前页面相对于文档顶部已经滚动的垂直距离

# 1. 获取视口坐标

  • 定义：返回元素相对于 视口左上角 的位置。
  • 示例：
js 
const rect = element.getBoundingClientRect();
console.log("元素相对视口位置：", rect.left, rect.top);
  • 返回值：包含 left、top、width、height 等信息。

# 2. 推算页面坐标

因为 getBoundingClientRect() 返回的是 视口坐标，所以要加上滚动值才能得到 页面坐标：

js 
const rect = element.getBoundingClientRect();
const pageX = rect.left + window.scrollX;
const pageY = rect.top + window.scrollY;

console.log("元素相对页面位置：", pageX, pageY);

# 3. 推算屏幕坐标

若想知道元素相对于 屏幕左上角 的位置，还需要加上浏览器窗口在屏幕上的偏移量：

js 
const rect = element.getBoundingClientRect();
const pageX = rect.left + window.scrollX;
const pageY = rect.top + window.scrollY;

const screenX = pageX + window.screenX;
const screenY = pageY + window.screenY;

console.log("元素相对屏幕位置：", screenX, screenY);

# 4. 应用场景

  • 元素绝对定位：浮层、菜单需要依附元素出现。
  • 截图/水印：基于元素位置绘制 Canvas 内容。
  • 跨窗口计算：在多屏环境下计算真实坐标。

# ✅ 总结：

  • 事件对象 适合获取鼠标事件的即时位置。
  • getBoundingClientRect 适合获取 DOM 元素的位置，并能通过计算转换成页面/屏幕坐标。

这样，你就能在 视口 / 页面 / 屏幕 三个维度中自由切换和计算坐标。

# 实战

实现：

js 
// 点击btn时页面滑动到section-1部分
html 
<div>
    <button class="btn--text btn--scroll-to">Learn more &DownArrow;</button>
</div>

<section class="section" id="section--1">
    <--!>内容</--!>
</section>

window.scrollTo({ top: scrollY, left: scrollX }) 的意思就是 让页面滚动到==文档(页面坐标）==中==坐标为 (scrollX, scrollY) 的位置==，即，是滚动到(scrollX, scrollY)，而不是滚动的距离

代码实现：

由于section1是DOM元素，获取页面坐标只有通过getBoundingClientRect()计算

js 
const btnScrollTo = document.querySelector('.btn--scroll-to');
const section1 = document.querySelector('#section--1');

btnScrollTo.addEventListener('click', e => {
  const section1Rect = section1.getBoundingClientRect(); // 返回视口坐标

  const scrollY = section1Rect.top + window.scrollY;
  const scrollX = section1Rect.left + window.scrollX;

  window.scrollTo({
    top: scrollY,
    left: scrollX,
    behavior: 'smooth',
  });
});
