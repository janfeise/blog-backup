# CSS 布局：Flex 与 Grid 系统梳理

模块 重点知识 说明
Flex 布局 一维布局 主要用于行或列方向的排版
Grid 布局 二维布局 同时控制行与列，适合整体页面结构
Grid 行列定义 grid-template-rows / columns 控制网格行列数量与尺寸
Grid 间隙 grid-row-gap / column-gap 控制行列之间的空隙
repeat 函数 repeat() 简化多行或多列的定义
fr 单位 fr Grid 专属的弹性比例单位
元素定位 grid-row / grid-column 指定元素在网格中的位置
实战练习 综合应用 使用 Grid 还原复杂布局

# Flex 布局概述

Flex 布局是一种典型的一维布局方案，其核心思想是沿着单一主轴进行排列，元素要么横向分布，要么纵向堆叠，而不会同时控制行与列，因此非常适合导航栏、列表、工具栏等线性结构的布局需求

Flex 的优势在于语义直观、学习成本低，并且在处理对齐方式、空间分配等问题时表现高效，这也是它在实际业务开发中被广泛采用的重要原因

# flex布局基础知识

  • 轴：flex布局由两个轴组成，主轴和侧轴组成，flex的所有核心属性都围绕这两条轴
  • 布局：flex容器内的元素可以沿着轴的方向进行布局，居中、开头、结尾、均匀布局等
  • 子元素可以自定义布局方向，摆脱父元素的统一布局

# flex 轴

flex布局可以自定义主轴，侧轴会跟着变化

# flex布局

在定了了轴的方向后，可以定义元素沿着轴的布局，在主轴方向居中，侧轴居中等

# Grid 布局概述

Grid 布局是一种二维布局方案，能够同时对行与列进行控制，是更加偏向页面级结构设计的布局工具，尤其适合后台管理系统、门户首页等结构复杂的页面场景

如果说 Flex 更像是在“沿着一条线排列元素”，那么 Grid 更接近于“先搭建一张网格，再将元素放入指定位置”，整体结构更加直观清晰

bilibili 首页的整体布局便体现了典型的 Grid 设计思路

# Grid 布局的基础知识

在正式使用 Grid 布局之前，需要理解几个关键概念，这些概念共同决定了网格的结构形态与最终的展示效果

  • 行与列：行和列用于控制网格的尺寸，间接决定页面中可展示的行数与列数，对应属性为 grid-template-rows 与 grid-template-columns
  • 间隙：间隙用于控制行与行、列与列之间的距离，对应属性为 grid-row-gap 与 grid-column-gap
  • repeat 函数：用于简化重复行或列的定义，提高代码的可维护性
  • fr 单位：用于对剩余空间进行比例分配
  • 跨区域：元素可以跨行或跨列，占据多个网格区域，span

# Grid 控制行与列

Grid 的核心能力体现在对行与列的显式定义上，通过grid-template-rows 和 grid-template-columns，可以清晰地指定每一行或每一列的尺寸，从而构建结构明确的网格体系

定义一个三行三列的基础网格结构

css 
.container {
  display: grid;
  grid-template-rows: 100px 200px 100px; // 3行
  grid-template-columns: 1fr 2fr 1fr; // 3列
}

上述代码中，行高采用固定像素值，列宽则使用 fr 单位进行比例分配，从而实现固定与自适应相结合的布局效果

# Grid 间隙设置

在 Grid 布局中，默认情况下各行与各列是紧密相连的，通过设置 grid-row-gap 与 grid-column-gap，可以让布局在视觉上更加舒展

如果行与列的间隙一致，可以使用简写形式，使代码更加简洁

css 
.container {
  display: grid;
  gap: 20px;
}

# repeat 函数的作用

当网格中包含较多行或列时，如果逐一书写尺寸定义，代码会显得冗长且不易维护，例如下面的写法可读性较差

css 
grid-template-rows: 100px 100px 100px 100px 100px 100px; // 六行，每行100px

此时可以使用 repeat 函数对重复结构进行抽象，使定义更加简洁直观

css 
grid-template-rows: repeat(6, 100px); /* 6 行，每行 100px */

repeat 本质上是语法层面的简化手段，不会改变布局能力，但能显著提升代码的清晰度与维护体验

# Grid 中的 fr 单位

fr 是 Grid 布局特有的弹性单位，用于按比例分配剩余可用空间，可以理解为对可分配空间进行“切分”

在同时存在固定尺寸与自适应区域的布局中，fr 能够自然地平衡空间分配，这是 Grid 相较于传统布局方式的一项重要优势

# Grid 指定元素位置

Grid 不仅可以定义整体结构，还支持对单个元素进行精确定位，其核心思路是通过“起始线 + 结束线”来描述元素在网格中的占位范围，从而实现显式、可控的布局设计

# 使用 grid-row-start 与 grid-column-start

首先可以通过 grid-row-start 和 grid-column-start 指定元素从哪一条网格线开始布局，用于确定元素的起点位置

text 
.item {
  grid-row-start: 1;
  grid-column-start: 2;
}

上述代码表示元素从第 1 行开始，从第 2 列开始放置，此时元素的结束位置仍由默认规则决定

# 使用 grid-row-end 与 grid-column-end

在明确起始位置后，可以进一步通过 grid-row-end 和 grid-column-end 指定元素结束于哪一条网格线，从而精确控制其占据的行数与列数

text 
.item {
  grid-row-start: 1;
  grid-row-end: 3;
  grid-column-start: 2;
  grid-column-end: 4;
}

该写法表示元素纵向占据第 1 到第 2 行，横向占据第 2 到第 3 列，布局范围完全由开发者显式控制

# 使用 span 表示跨越行或列

span翻译：跨度

如果不关心具体结束线编号，也可以使用 span 关键字表示元素跨越的行数或列数，从而提升可读性

text 
.item {
  grid-row-start: 1;
  grid-row-end: span 2;
  grid-column-start: 2;
  grid-column-end: span 2;
}

这种方式更贴近“占几行、占几列”的直觉表达，在动态布局中尤为常见

# grid-row 与 grid-column 简写形式

在实际开发中，更推荐使用 grid-row 和 grid-column 的简写形式，将起始线与结束线合并书写，使代码更加紧凑清晰

css 
.item {
  grid-row: 1 / 3;
  grid-column: 2 / 4;
}

也可以结合 span 使用，表达更加语义化

css 
.item {
  grid-row: 1 / span 2;
  grid-column: 2 / span 2;
}

# 使用 -1 表示到最后一行或最后一列

在 Grid 布局中，除了使用 span 表示跨越的行数或列数外，还可以使用 -1 作为结束线编号，表示元素一直延伸到最后一行或最后一列

-1 代表倒数第一条网格线，无论网格的行数或列数如何变化，元素都会自动延伸到最末端，因此在自适应布局中非常实用

text 
.item {
  grid-row-start: 2;
  grid-row-end: -1;
}

上述写法表示元素从第 2 行开始，一直占据到最后一行结束，无需关心具体的总行数

同样的规则也适用于列方向

text 
.item {
  grid-column-start: 1;
  grid-column-end: -1;
}

在简写形式中，-1 也可以直接与 grid-row 和 grid-column 搭配使用

text 
.item {
  grid-row: 2 / -1;
  grid-column: 1 / -1;
}

相较于 span 更关注“占多少行或列”，-1 更关注“延伸到哪里”，二者结合使用，可以在不同布局需求下灵活选择最合适的表达方式
