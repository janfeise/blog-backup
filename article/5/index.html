# Intersection Observer API 详解

一级主题 二级主题 说明 / 关键点
Intersection Observer API 功能点 元素==进入/离开==可视区域时执行动作，如：添加/移除类名
使用方法 第一步 创建观察者 new IntersectionObserver(callback, options)
第二步 确定观察对象 observer.observe(element)
第三步 编写回调函数，利用 entries / observer 来实现逻辑
回调函数 参数 entries 一个数组，包含被观察元素的可见性变化信息
参数 observer 观察者实例，可用来取消观察
entries 的元素 entry isIntersecting 是否满足阈值条件（进入 / 离开）
target 当前进入或离开可视区域的 DOM 元素本身
触发时机 ==初始化时也会触发一次，无论是否满足阈值==
option 参数 root 作为可视区域的元素（默认是浏览器视口）
threshold 阈值（0 ~ 1），表示多少比例进入 root 区域时触发
rootMargin 扩大或缩小 root 区域（正值扩大，负值缩小）
特点 调用时机 初始化时回调会执行一次
常见用法 图片懒加载、动画触发、元素显示/隐藏

# 一、作用

Intersection Observer API 用来异步监听目标元素是否==进入==或==离开==指定的可视区域，<u>==当可见比例达到设定的 threshold 时触发回调函数==</u>

observe：观察

intersection：交叉点**[ˌɪntərˈsekʃn]**

threshold：阈值，临界点**[ˈθreʃ，hoʊld]**

常见应用场景：

  • 懒加载（图片进入视口时再加载）
  • 动画触发（滚动到某个元素时启动动画）
  • 元素显隐控制（添加 / 移除类名）

# 二、使用方法

# 第一步：创建观察者

使用 new IntersectionObserver(callback, options)：

  • callback：回调函数，当元素进入或离开可视区域时触发
  • options：配置对象，主要包含
    • root：以哪个元素为可视区域（默认是 viewport）
    • threshold：阈值（进入多少比例时触发回调，取值 0 ~ 1）
    • rootMargin：扩展或收缩 root 区域（正值扩大，负值缩小）

# 第二步：确定观察对象

js 
observer.observe(element);

# 第三步：编写回调函数

js 
const callback = (entries, observer) => {
  // entries：本次触发的可见性变化集合
  // observer：观察者实例
};

# 三、回调函数的两个参数详解

# 参数一：entries

  • entries 是一个 数组，每一项都是一个 IntersectionObserverEntry 对象，表示被观察元素的可见性变化。

  • 如果 threshold 只设置一个值（比如 0.5），通常只有一个元素在数组里，可以直接==解构==：

    js 
    const [entry] = entries; // const [a] = [1]; a = 1;

  • 常用的 entry 属性：

    • entry.isIntersecting：是否进入阈值条件
    • entry.intersectionRatio：可见比例
    • entry.boundingClientRect：目标元素矩形信息
    • ==entry.target==：触发观察的 DOM 元素本身（非常常用）

# 参数二：observer

  • observer 就是 IntersectionObserver 实例本身。

  • 在一些场景下，比如==只需要观察一次==，可以用它来取消观察：

    js 
    observer.unobserve(entry.target);

entry.target

  • entry.target 表示==当前正在被观察==并==触发可见性变化==的元素，即你在 observe() 方法里传入的 DOM 元素。

  • 比如：

    js 
    observer.observe(img);

    当 img 进入/离开视口时，entry.target === img。

# 四、isIntersecting 的判断逻辑

Intersection Observer 的回调会在元素 进入和离开 可视区域时都触发：

  • 进入时：可见比例 由 < threshold → ≥ threshold，isIntersecting = true
  • 离开时：可见比例 由 ≥ threshold → < threshold，isIntersecting = false

# 五、rootMargin详解

rootMargin可改变root区域：==正值扩大，负值缩小==

例：

js 
const options = {
  rootMargin: '100px 0px'
};

意思是：视口上边距和下边距扩大100px，常用于懒加载

# 六、特点与注意点

  1. 初始化时会执行一次回调 —— 无论元素是否在可视区域内。可用 isIntersecting 来判断是否真正进入。
  2. 可同时观察多个元素。
  3. 对性能友好，避免频繁监听 scroll 事件。

✅ 总结一句话： Intersection Observer API 是前端性能优化的利器，既能减少手动计算 DOM，可用于懒加载、滚动动画触发等场景

# 实战

js 
///////////////////////////////////////
// 图片懒加载：低分辨率图片 + 模糊滤镜 + loading动画
const lazyImgs = document.querySelectorAll('img[data-src]');

const lazyImgsObserver = new IntersectionObserver(loadImg, {
  root: null,
  threshold: 0,
  rootMargin: '200px',
});

lazyImgs.forEach(img => lazyImgsObserver.observe(img));


// 需放到前面
const loadImg = function (entries, observer) {
  const [entry] = entries;

  // guard line
  if (!entry.isIntersecting) return;

  console.log(entry);
  entry.target.src = entry.target.dataset.src; // 浏览器重新获取图片，会触发load事件

  entry.target.addEventListener('load', function () {
    this.classList.remove('lazy-img');

    // 获取上一个兄弟元素: loading动画
    const loader = this.previousElementSibling;
    if (loader) loader.style.display = 'none';
  });

  observer.unobserve(entry.target);
};
