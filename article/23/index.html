# 一、什么是图片懒加载？

图片懒加载（Lazy Load） 是一种性能优化策略： 当页面中有大量图片时，不必在首屏==一次性加载所有图片==，而是先加载占位图或低分辨率版本，等到用户滚动到对应位置时，再加载清晰大图。

好处：

  • ✅ 提升首屏加载速度
  • ✅ 减少不必要的带宽消耗
  • ✅ 改善用户体验

# 二、基本实现思路

  1. 占位图 + 模糊滤镜

    • 使用低分辨率图片（体积小、加载快）。

    • 在 CSS 中添加模糊效果：

      css 
      .blur {
  filter: blur(10px);
  transition: filter 0.5s;
}

    • 页面加载时，低清晰度图显示为模糊。

  2. 使用 data-src 存储高清图路径

    • HTML 结构示例：

      html 
      <img src="low.jpg" data-src="high.jpg" class="blur" alt="风景图">

    • src → 低清晰度图或占位图；

    • data-src → 真正的高清图。

  3. 进入可视区时替换图片

    js 
    const imgs = document.querySelectorAll("img[data-src]");

const loadImg = (img) => {
  img.src = img.dataset.src;   // 替换成高清图
  img.addEventListener("load", () => {
    img.classList.remove("blur"); // 去除模糊滤镜
  });
};
    • 替换 src 后，浏览器会重新请求资源。
    • 监听 load，确保高清图加载完成后再去掉模糊。

# 三、关键点解析

# 1. 并不是所有图片都需要懒加载

  • logo、图标、按钮图标 → 页面一加载就需要显示，不适合懒加载。
  • 因此不能用 document.querySelectorAll("img")。

👉 正确选择方式：

js 
document.querySelectorAll("img[data-src]");

即只选择带有 data-src 的图片。

# 2. data 属性与 dataset

  • HTML5 提供了 data-* 自定义属性，专门存储开发者定义的数据。

  • 在 JS 中可以这样获取：

    js 
    const img = document.querySelector("img");
console.log(img.dataset.src); // 取出 data-src 的值

# 3. load 事件触发时机

  • 当 src 替换为高清图时，浏览器会重新发起请求。
  • 只有在资源请求完成后，load 才会触发。
  • 这就是去除滤镜的最佳时机。
  • 可通过 DevTools → Network → Slow 3G 观察效果。

# ==四、实战==

HTML结构：使用 data-src 存储<u>高分辨率图片地址</u>，并添加模糊滤镜 lazy-img

html 
<img
     src="img/digital-lazy.jpg"
     data-src="img/digital.jpg"
     alt="Computer"
     class="features__img lazy-img"
/>

css滤镜：实现模糊滤镜

css 
.lazy-img {
  filter: blur(20px);
}

js：懒加载

js 
// 图片懒加载
const lazyImgs = document.querySelectorAll('img[data-src]'); // 获取所有需要懒加载的图片

const lazyImgsObserver = new IntersectionObserver(loadImg, {
  root: null,
  threshold: 0,
  rootMargin: '200px',
});

lazyImgs.forEach(img => lazyImgsObserver.observe(img));

// 实际操作时需将下面的代码放置在前面
const loadImg = function (entries, observer) {
  const [entry] = entries;

  // guard line
  if (!entry.isIntersecting) return;

  console.log(entry);
  entry.target.src = entry.target.dataset.src; // 浏览器重新获取图片，会触发load事件

  entry.target.addEventListener('load', function () {
    this.classList.remove('lazy-img');
  });

  observer.unobserve(entry.target); // 一次懒加载即可取消
};

# 五、使用场景

  • 电商网站商品列表：商品图很多，懒加载可大幅提升首屏速度。
  • 资讯流 / 瀑布流：用户不一定会滚动到底部，懒加载节省大量流量。
  • 图片展示网站：如摄影站、图床等。

# 六、总结

图片懒加载的核心是：

  1. 低清晰度占位（视觉不突兀）。
  2. 进入可视区时替换高清图。
  3. 等待 load 事件后移除滤镜。
  4. 通过 img[data-src] 精确选择目标。
  5. 结合 Intersection Observer 提升性能。

这是前端性能优化中最常见也最实用的一个技巧。

# ==补充：img[data-src]==

# 一、语法解析

css 
img[data-src]

这是 CSS 属性选择器 的一种写法，意思是：

  • 选择所有带有 data-src 属性的 <img> 标签。
  • 不要求 data-src 里面的值是什么，只要存在这个属性即可被选中。

👉 举例：

html 
<img src="low.jpg" data-src="high.jpg" alt="懒加载图片">
<img src="logo.png" alt="网站 logo">
  • 第一个 <img> 有 data-src，会被 img[data-src] 选中。
  • 第二个 <img> 没有 data-src，不会被选中。

# 二、为什么用它？

在懒加载中，我们要区分：

  • 需要懒加载的图片 → 通常有一个占位 src，真实路径存在 data-src。
  • 不需要懒加载的图片 → 比如 logo、图标、导航按钮，一进入页面就要加载。

如果直接用 document.querySelectorAll("img")：

  • 会把所有图片都选出来，包括不该懒加载的。
  • 可能导致 logo 被错误地处理，页面闪烁。

👉 所以正确做法：

js 
const lazyImgs = document.querySelectorAll("img[data-src]");

这样只会拿到需要懒加载的图片。

# ==补充：data-* 属性的规则==

  • data-* 是 HTML5 提供的自定义属性机制。

  • 写在标签上的形式是：

    html 
    <img data-src="high.jpg">

  • 在 JS 中可以通过 dataset 获取：

    js 
    const img = document.querySelector("img[data-src]");
console.log(img.dataset.src); // 输出 "high.jpg"

# 扩展：精确匹配属性值

除了 img[data-src]（只要有 data-src 就选中），还可以写：

  • 指定属性值：

    css 
    img[data-src="high.jpg"] { border: 2px solid red; }

    → 只选择 data-src="high.jpg" 的图片。

  • 属性值开头匹配：

    css 
    img[data-src^="https://"] { ... }

    → 选择所有以 https:// 开头的路径。

  • 属性值结尾匹配：

    css 
    img[data-src$=".jpg"] { ... }

    → 选择所有 .jpg 结尾的图片。

  • 属性值包含某段字符串：

    css 
    img[data-src*="banner"] { ... }

    → 选择路径里包含 banner 的图片。

✅ 总结：

  • img[data-src] 是属性选择器，作用是「选择所有带有 data-src 属性的图片」。
  • 在懒加载中，它能帮我们精准过滤出需要懒加载的目标，而不影响 logo、图标等无需处理的图片。
  • 搭配 dataset 可以读取真实路径，实现从低清晰度 → 高清晰度的替换。
