2026/03/26 开启了人生第一次实习

# 求职

2026/03，大三下学期开学时，便开始准备简历，3月初开始投递，半个月后便找到了一份实习，总计只投递了30多份简历（很幸运，入职后才知道是由于上一位前端开发的人员离职而空出来的职位）

03/19 进行了线下面试，面试时间很短不到半小时，技术面和HR面都结束了

技术面，mentor 简单问了我技术栈和使用的组件库（前端嘛，少不了组件库），vue3 + element plus（公司使用的是ant-design-vue），聊了聊项目和 git，与其说是面试，不如说是聊聊天，过程很短，准备的八股几乎没问😂

HR面，由于 mentor 那边说没什么问题，HR面也很快，聊了聊专业、绩点、最近在看的书，几分钟便结束了，不过HR问我薪资时，我直接拉倒最高 200/天（招聘 jd 中的薪资是 150-200/天），HR没有明显表露什么，很平淡，但最终给的薪资是 160/天，纯 160，没有交通补贴、餐补，不过在成都160 一天的实习，感觉还是可以，公司的实习薪资分布大致是：

  • 前端：150-200
  • 后端：170-200
  • 算法：200-300

上四休三，在协商实习天数时，由于大三上还是有几门专业课，不过我的课大多集中在周一，周一满课，其余几天平均一天不到一节课，便协商周一上课，周二到周五上班，每周上 4 天班（也是过上了上四休三的日子）

面试结果很快便出了，一周后发offer，并入职——03/26

# 入职，前端开发

03/26（周四） 入职，开发岗公司发了一台主机和HKC显示屏（其它职位默认是Mac笔记本+显示屏），配置还不错，32G内存，1TB硬盘，第一天没有什么事，配置环境、拉项目仓库代码、相关账号和权限处理，第一天基本就结束了

03/27（周五）这天也没什么事，mentor 让我熟悉熟悉项目，把项目启动起来，看看代码即可，不过启动项目还是遇到了困难

cmd 
npm run dev

诶失败，嗷，看了下 package.json 文件，发现启动命令是：

cmd 
npm run serve

很好，控制台成功输出，项目启动成功？诶浏览器打开怎么直接白屏了……，琢磨半天还是没发现问题，遂请教 mentor（文档？没有文档。。。），原来公司前端项目使用了 microapp ，类似于后端的微服务架构，将前端多个项目组合起来，形成了一个统一管理的 platform 项目，需通过 platform 这个项目去访问其它前端项目

microapp 文档：https://jd-opensource.github.io/micro-app/

项目成功启动，后续便是看代码了？！代码实在太多了，慢慢看吧（后来才慢慢总结出来，熟悉一个项目，不是去看代码，而是看这个项目实现的业务是什么，再去看代码是怎么实现业务的，而不是怼着代码看😂）

很好啊，两天便混过去了，320 块大洋到手~，三休，周末 + 周一（上课）

后面一周，也没有什么任务，再看看代码，熟悉熟悉项目，到了周四时才分配给了一个小需求，把文字更新（文字A更新为文字B）和一个弹窗处理，这时还是古法编程，纯手搓，而且是第一次写需求，还是手动处理比较好，这样也能更熟悉项目，文字更改和弹窗处理都没有什么难度，在现有代码基础上略作更改即可，完成后确定没问题再push到仓库，这时对项目大概有了一个了解，后面便进入正常的业务开发了

# 公司软件开发流程

公司软件的开发流程与个人项目开发流程完全不同，公司的开发人员更像一个<u>工具人</u>，完成上面需求的工具人，流程大致是：

text 
用户需求
    ↓
产品梳理，输出 PRD
    ↓
评审（内审、外审……）
    ↓
  估时
    ↓
前端、后端开发
    ↓
前后端联调
    ↓
  测试
    ↓
  上线
    ↓
产品验收

PRD: 产品需求文档（Product Requirement Document），后续开发、测试都是以该文档为标准

不过每次开会评审时，都很头疼，一是刚入职不了解公司的业务，二是产品讲的话太头疼，明明都是中文，怎么凑一起就不知道在说什么了😅，PRD原型文档也看的头疼，文字一堆堆。。。

每次评审后，mentor 便问我这一期想做哪块？我一般选择较为简单的一两个模块，然后进行估时，后续就正常进入开发的流程，并与负责该模块的后端沟通

估时：为实现该模块的大概耗时时间进行估时，由于产品梳理的估时文档较为笼统，mentor 教我单独开一个文档，对模块进行估时：该模块有哪些功能？难点有哪些？……，先自己梳理一下模块的耗时，然后再去填估时文档

第一次负责一个完整的模块时，还在古法编程，但开始时的第一天就发现不对了，太慢了，但没有放弃，第二天仍尝试古法编程，但过了半天后，看着手写代码的进度，实在太慢，在预定时间内根本完不成，遂转 AI 编程（如果在学校估计一时半会儿不会运用到日常学习中）

使用的是：cc-switch + claude code 接 deepseek v4 pro（并开启 1m 上下文）

ds 很快啊，库库写，效率贼高，但看着写的代码，满头黑线，代码又臭又长，还没有注释，想让AI一次完成整个模块太不现实了，mentor 看了我的代码后也是说代码不利于维护（很委婉了），有了经验后便转换思路，分步实现：

  1. 搭建基础框架：该模块有哪些页面？页面使用的公共组件有哪些？先把基础框架搭建起来（有了一个壳子）
  2. 核心功能+组件拆分：该模块的核心功能是什么？是否需要拆分为组件？进一步实现核心功能和组件
  3. 查看原型：根据原型上的细节进行调整

对模块进行拆分后，AI 一步步实现便好了许多，这个过程也积累了相关的 AI 使用技巧

  1. 先规划，后实现：先让 claude code 进行规划，输出规划后，在根据实际业务进行规划调整，当规划大方向上没有问题后才进入代码编写
  2. 总结了个人前端开发时所需的prompt：前端开发prompt，后续开发时这个 prompt 基本都伴随我整个时间线，直至实习结束

开发完成后，会进行测试，并将 bug 汇总，公司使用的是 pingcode 对 bug 进行统计

bug改完后便是上线，上线的时间是晚上，白天一般有用户在使用，导致上线那天基本都要加班

# 加班？20元

很操蛋的规定，加班没有加班费，正常工作时间是9点上班，18点下班，但加班是没有加班费的，只有 20 块补贴，加班到 20:30 补贴 20 块，也就是说加班两个半小时，20块，时薪高达 8r/h，说实话我不知道老板是咋想的，由于是第一次工作，不知道其它公司是不是也是这样，但你这20块不如不发

真想狠狠把这 20块 甩老板脸上😅😅😅

不过，软件开发这一行免不了加班，系统上线要加班，赶工期要加班，确实是挺常见的情况

对加班的看法：一天的上班时间已经占据了太多太多，若仍需要长时间的加班（每天都加班……），把仅剩的一点时间也投入公司中，我是拒绝的，基本到点就走

# 时间，很重要

系统上线时间一般是确定的，比如下个月上线，那么这个月就得开发完成，并预留时间给测试人员进行测试，对于开发而言，哪一步会严重影响后续的步骤呢？——产品，只有产品的需求评审通过后，PRD文档确定了，开发才能真正去实现，虽然开发人员可以预先根据 PRD 文档处理一部分内容，但若产品的需求没有确定，那么开发是无法写代码的

如：这个需求到底是A还是B，应该是唯一且确定的，若没有确定，在需求A和B之间摇摆，那么开发又如何去落实呢？

对于前端开发而言，还存在一个制约——后端接口的实现时间，实习时也在这里栽了一个坑，不能等后端所有接口都完成了才去要接口文档，而是根据当前所负责的模块，把主要接口梳理出来，若一个接口直接阻塞了前端的开发，那么是需要和后端沟通，让后端优先完成这个接口的

不然，前端一直在等着后端的接口，时间过去了，DDL 可不会等你，最终免不了加班

真正挤占开发时间的是：产品的原型和评审通过的时间，这段时间耗费越久，开发时间越少

前端开发额外注意：后端接口完成时间，不能静静等待后端完成，而是要根据当前负责模块的流程，梳理优先实现的接口

# 头疼，没有交互

在实习时，由于只有产品的原型和UI的静态设计稿，缺少可交互的原型（一般是使用 figma 实现），此时对于前端开发人员来说就头疼了，得自己梳理交互，上一个状态是什么？由什么触发更改？下一个状态又是什么？这些都没有进行说明，是留白的，得自己进行梳理，从原型的一堆文字中找出交互，十分头疼，若有交互的原型，那么无疑会方便许多，但可惜的是，并没有。。。

留白最是头疼，对于 AI 编程也是，AI 对于没有说明之处，即留白的地方往往会出现幻觉，自行“脑补”，有时 review 又没有发现，最终留下隐患

# 职业定位

工具人，无论是前端开发，还是后端开发，乃至其它大多数岗位，都是工具人，没有决定权，只是一颗螺丝钉

每次需求写完，push 到仓库时，都有一种被榨干的感觉😨

# 煎熬，通勤时间太长太长

大三下还是住在学校的，并没有在公司附近租房，从学校到公司距离将近 30km，还好地铁是直达的，从首站做坐到末站的前一站，光是做地铁都得 40min，整个通勤时间长达 1h15min，一天的通勤时间有 2.5h，太长太长了，这段实习的最大的煎熬就是通勤

而且，即使光坐在工位上，上了一天班后整个人的精气神感觉都被抽干了，下班后坐地铁回学校时完全没精神，只想刷刷抖音，听听歌，下班后学习？不存在的

# 对工资的看法

起初认为160 一天，我值哪么多吗？而且入职那一两周基本没什么事做，算是坐着拿钱，但真正入职几个月后，不这么看了

从入职那一刻起，你便受到了公司的约束，一周四天，每天早上 7:30 起床，9 点打卡，18点下班，19:30 左右才能回到寝室，吃个晚饭、洗漱一下大概就晚上8、9点了，一天的时间基本耗完，而且上班后时间流逝的很快很快，一周又一周，一个月便过去了，一月又一月，大三也结束了

也就是从入职那一刻起，你生命中的这段时光便交给了公司，换取工资，只是一个交换，至于这段时光公司实现了什么，我并不关心，盈利的多少也与我无关，毕竟多的钱又不会分到我头上，若是亏损估计还得担心是否会被恶意调岗，降薪

双休？周末？是的，有双休，还有不上班的周一，但上班并不局限于工作时段，下班后，甚至周末也会想着工作上的事情，代码写到哪了？业务完成到哪了？下一个业务要怎么写？入睡前偶尔也会想到这些

参与工作的这段时间，你的生命便和工作深深绑定，不可能做到完全切割的，下班或者周末就清空脑海，完全将工作抛之脑后，是不可能的，甚至你的潜意识也会想着工作中的一些事情

工作只是一次交换，生命与工资的交换

# 开销，工作后的开销

相较于学校的开销，工作后开销会更多，餐食更贵、每天通勤固定支出18元左右（地铁打9折），工作后的开销大致有：

  • 早餐：7，牛奶 + 面包
  • 午餐：18，平均下来大概一顿18，公司楼下的商铺挺贵的，面食一两13，二两15，炒饭或者盖饭大概18一份；有次光是午餐就花费了28，由于分量较小，点的第一份面食 10 块（甜水面），完全不够吃，又点了一份 18 块的肥肠面，毕竟不能饿着肚子渡过下午
  • 晚餐：16，大多数是点外卖，塔斯汀、华莱土、享哆味……
  • 通勤：18，早上和晚上分别赶地铁，并骑共享单车，地铁大概 7 块，共享单车 2.5（买了月卡会便宜许多）

因此，工作后固定开销大概 59 块，一个月上 18 天班，工作日花费 1062 元，剩余12天，在学校花费会小许多，大概一天35，共计 420，那么一个月大概固定开销有 1062 + 420 = 1482

除了固定开销，可能存在其它支出，如：洗澡费用、饮水费用、洗衣机清洗衣物费用、小吃费用、寝室电费……，那么一个月大概支出 2000 元往上，高于只在学校时花费的费用

虽然学校花费少，但大一到大三完全没有存住钱，毕竟存钱主要取决于来源，没有源头光是节流又怎能存住钱呢

# 大学生活真tm美好

工作后第一感觉便是，大学生活太tm美好了，空闲时间多、有周末、有寒暑假、父母还每月发生活费，真的太美好了

但，美好的背后是父母替我遮挡了生活的困难，生活费一个月 2000，我的实习一个月上班18天，工资只有 2880，若是租房，自己负责饮食等费用，一个月基本没有结余，妥妥付费上班

# 作息规律，变胖？

本想着工作后，作息规律了，一日三餐也挺健康的，精神应该更好，身体应该会变瘦吧，但不是的，反而整个人胖了一圈，也总是感觉睡眠不足。。。上班老打哈欠（特别是评审时😂）

早餐：牛奶 + 糯米鸡/面包

午餐：公司楼下的商铺，如：面馆、快餐店、米线、饭店等

晚餐：大多时候点外卖

作息：寝室 23 点熄灯，23:30 - 24:00 入睡，早上 07:30，左右起床

# 入职步骤：还原点和系统映像

第一次工作没有经验，离职时只将各个软件卸载、退出登录，我并没有将电脑重置😯

Windows 电脑建立还原点，电脑出现问题时直接还原（但已登录的用户数据不会还原，仍存在），而系统映像才能将电脑所有数据重置（离职时也可以直接重置电脑）

# 工作后的变化，作息

工作后，作息挺规律的，7点多就起床了，导致离职后，现在也差不多7,8点就醒了，睡懒觉的时光已经离我而去了

  2. 双休

虽然有些大厂不存在上述的岗位，但作为秋招的练手面试还是可以的
