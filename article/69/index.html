# figma 绘制设计稿

Figma 是一款基于云端的团队协作界面设计与原型制作工具

在大二以及公司实习时，便已经接触了 figma，此次主题的设计稿也是在 figma 中完成的，当然是由 ChatGPT-6 Astra 实现的，步骤大致如下：

  • 在 codex 中安装 figma mcp
  • codex 通过 mcp 绘制设计稿

安装 figma mcp 后，打开博客项目的工作目录，将博客主题设计的想法告诉给codex即可

prompt 
UI主题色设计：为博客设计主题色与配套的UI
要求：
1. 浅色背景，避免以图片为背景遮挡文字
2. 绿色系主题色，生命的颜色
3. 避免强烈的对比，如：纯白与纯黑
4. 考虑使用纹理、线条、颜色过渡等元素
5. 风格：简洁风
6. 忽略 about 页面，about页面的UI已经完成，无需考虑
博客要素提取，当前博客包含以下元素：
1. 首页：左右布局，左侧nav，右侧的文章card
2. 文章详情页：极简风，但背景可以使用浅色、不遮挡文字的元素进行修饰
3. 归档页面与详情页一致
4. 空间：左右布局，左侧nav，右侧数据，当前右侧顶部的主要元素是一个球体，右侧下方则是item项
5.
工具与skill：
1. 使用figma设计并绘制UI

ChatGPT-6 Astra 初版便几乎完成了整个设计稿，后续也只是在此基础上进行了微调

# 绕过 figma mcp 的额度限制

figma mcp 存在额度限制，初版设计稿完成了大部分内容后额度便耗完了，额度大致如下：

方案 Professional 价格 MCP 额度 Figma Design 权限 适合你的场景
Starter 免费 最多 20 次/月 基础 偶尔测试
Collab $3/月 最多 6 次/月 查看/评论 不适合 MCP
Dev $12/月 200 次/天，10 次/分钟 查看/评论 + Dev Mode Figma → 代码
Full $16/月 200 次/天，10 次/分钟 完整 Design 权限 AI 创建/修改 Figma UI

由于额度的限制是按月更新，不可能等到下个月再来设计，而 collab 3$ 方案的额度却更少，想继续使用 mcp 至少得 dev 12$，有点太贵了，毕竟平时使用的并不多，于是网上搜索了相关信息，了解到可以通过 「figma 客户端 + figWright项目」在本地使用figma，便尝试了一下：

prompt 
完成：figma mcp的使用
背景：由于figma mcp额度有限，此时通过下载figma客户端，以及github项目的figWright进行替代
下载位置：D:\figmaFile

codex 会进行 figma 客户端以及 figwright 项目的下载，下载完成后打开 figma 客户端，并配置 figWright 插件：

配置完成后进行连接即可，在此点击上图的 1、2、3步骤，此时会出现弹窗，在弹窗中选择「Figwright」，然后会出现一个小弹窗，显示已连接

此时便能让 codex 继续完善设计稿了
