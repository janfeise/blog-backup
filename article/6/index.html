# JavaScript DOM 操作：选择、创建、插入与删除

多元素选择（静态） querySelectorAll 返回 NodeList（不可自动更新，可用 [...nodelist] 转数组）

按 ID getElementById 返回单个匹配元素

# 1. DOM 元素选择

JavaScript 提供了多种方法来获取页面上的元素，我们可以按精度和用途来分类。

# 1.1 获取整个文档

  • document.documentElement：返回 <html> 元素。
  • document.head：返回 <head> 元素。
  • document.body：返回 <body> 元素。

# 1.2 按选择器获取

  • 单元素：document.querySelector(selector) 返回首个匹配元素。

  • 多元素（静态集合）：document.querySelectorAll(selector) 返回 NodeList，不可自动更新，可用展开运算符转为数组：

    js 
    const list = [...document.querySelectorAll('p')];

# 1.3 按标签或类名获取

  • document.getElementsByTagName(tag)：返回 动态 更新的 HTMLCollection。

    HTML由 tag + content 组成

  • document.getElementsByClassName(className)：同样返回动态集合。

# 1.4 按 ID 获取

  • document.getElementById(id)：返回单个元素（或 null）。

注意

  • querySelectorAll 返回的结果不会自动反映 DOM 变化，而 getElementsByTagName 等方法返回的 HTMLCollection 是实时更新的。
  • 动态集合性能稍差，但无需手动重新查询。

# 2. 创建与插入元素

# 2.1 使用 insertAdjacentHTML

语法：

js 
element.insertAdjacentHTML(position, text);

position 可选值：

  • "beforebegin"：元素自身前面
  • "afterbegin"：元素内部最前面
  • "beforeend"：元素内部最后面
  • "afterend"：元素自身后面

示例：

html 
<div id="container">
  <p>已有段落</p>
</div>
js 
const container = document.getElementById("container");
container.insertAdjacentHTML("beforeend", "<p>新段落</p>");

结果：

html 
<div id="container">
  <p>已有段落</p>
  <p>新段落</p>
</div>

优点：

  • 不会清空原内容（相比 innerHTML += 更安全）
  • 性能好，不重新解析整个 DOM
  • 精确控制位置

# 2.2 在 DOM 外部插入

  • element.before(newNode)
  • element.after(newNode)

# 2.3 在 DOM 内部插入

  • element.prepend(newNode)：插入到第一个子节点前
  • element.append(newNode)：插入到最后一个子节点后

# 2.4 克隆节点

由于一个 DOM 节点只能存在于一个位置，如果需要在多个位置插入相同内容，需要先克隆：

js 
const clone = element.cloneNode(true); // true 表示深拷贝

# 3. 删除元素

# 3.1 现代方法

js 
element.remove();

# 3.2 旧方法

js 
element.parentElement.removeChild(element);

原因：旧浏览器不支持 .remove() 方法，因此需要==通过父节点手动移除子节点==。

# 4. 常用属性与方法

模块 子模块 关键方法 / 属性 功能说明
样式操作 内联样式 element.style.color``element.style.backgroundColor 修改元素内联样式
计算样式 getComputedStyle(element) 获取最终渲染后的样式值
属性操作 属性增删查 setAttribute / getAttribute / removeAttribute 设置、获取或删除 HTML 属性

文本与 HTML 文本 textContent 设置或获取纯文本内容
HTML innerHTML / outerHTML 设置或获取 HTML 内容，替换整个元素
节点操作 节点增删 appendChild / insertBefore / removeChild 插入或删除子节点
克隆节点 cloneNode(true/false) 复制节点，深拷贝或浅拷贝
包含关系 contains 判断节点是否包含另一个节点

# 4.1 样式操作

js 
element.style.color = "red";       // 内联样式设置
element.style.backgroundColor = "#eee";

⚠️ 注意：CSS 属性用驼峰命名，如 background-color → backgroundColor

js 
getComputedStyle(element).color;   // 获取最终计算后的样式
/**
* .style.color 只能获取 内联样式 或直接赋值的样式
* 
* getComputedStyle(element).color 可以获取 元素最终在页面上实际显示的样式值，非常适合调试或 JS * 动态计算样式时使用
*/

# 4.2 属性操作

js 
element.setAttribute("id", "myId");   // 设置属性
element.getAttribute("id");           // 获取属性值
element.removeAttribute("id");        // 删除属性

# 4.3 添加 / 删除类名

js 
element.classList.add("active");
element.classList.remove("hidden");
element.classList.toggle("open");     // 切换类
element.classList.contains("active"); // 判断是否存在类

# 4.4 文本与 HTML

js 
element.textContent = "纯文本内容";       // 只操作文本
element.innerHTML = "<strong>带标签内容</strong>"; // 操作 HTML
element.outerHTML = "<div>替换整个元素</div>";     // 替换自身及内容

# 4.5 节点操作

js 
element.appendChild(newNode);        // 插入子节点
element.insertBefore(newNode, refNode); // 在某个节点前插入
element.removeChild(childNode);      // 移除子节点
element.cloneNode(true);             // 克隆节点（深拷贝）
element.contains(otherNode);         // 判断是否包含某个节点

# 4.6 查找节点关系

js 
element.parentElement;    // 父节点
element.children;         // 子元素集合
element.firstElementChild; // 第一个子元素
element.lastElementChild;  // 最后一个子元素
element.nextElementSibling; // 下一个兄弟元素
element.previousElementSibling; // 上一个兄弟元素

# 4.7 事件操作

js 
element.addEventListener("click", handleClick); // 添加事件
element.removeEventListener("click", handleClick); // 移除事件

# 4.8 数据存储（自定义属性）

js 
// <button data-id="1"></button>

element.dataset.id = "123";  // 通过 data-* 属性存储数据
console.log(element.dataset.id);

# ==补充：==克隆节点：让同一元素出现在多个位置

由于一个 DOM 节点在页面中只能存在于一个位置，如果你直接插入已存在的节点，它会 从原位置被移动 到新位置，而不是复制一份。 如果需要在多个位置显示相同的内容，就必须先 克隆 节点。

js 
const clone = element.cloneNode(true); // true 表示深拷贝（包含子节点和属性）

# 示例：同一个元素出现在多个位置

HTML：

html 
<ul id="list1"></ul>
<ul id="list2"></ul>
<p id="item">我是要被克隆的段落</p>

JS：

js 
const list1 = document.getElementById("list1");
const list2 = document.getElementById("list2");
const item = document.getElementById("item");

// 将原节点插入到 list1 中
list1.append(item); // 在list1内部，末尾插入

// 克隆一份（深拷贝），插入到 list2 中
const clonedItem = item.cloneNode(true);
list2.append(clonedItem);

结果（页面渲染）：

html 
<ul id="list1">
  <p id="item">我是要被克隆的段落</p>
</ul>
<ul id="list2">
  <p id="item">我是要被克隆的段落</p>
</ul>

💡 注意：

  • 如果 cloneNode(false)，只会复制元素本身，不会包含子节点。

    克隆的元素即使内容相同，也是新的 DOM 节点，事件绑定不会自动复制，需要手动重新绑定。

# ==补充：==setAttribute详解

setAttribute 是操作 DOM 元素属性的高频方法之一，用于 给元素设置或修改属性值。

# 1. 基本语法

js 
element.setAttribute(name, value);
  • element：目标 DOM 元素
  • name：要设置的属性名（字符串）
  • value：属性值（字符串）

返回值：无，只是修改或新增属性

# 2. 功能作用

  1. 新增属性：元素原本没有这个属性时，会创建该属性。
  2. 修改属性：元素已有该属性时，会覆盖原有值。
  3. 兼容 HTML 特性：可用于设置 HTML 属性（如 id、class、href、src 等）以及自定义属性（如 data-*）。

# 3. 示例

# 3.1 设置 ID

html 
<p id="demo">Hello</p>
js 
const p = document.getElementById("demo");
p.setAttribute("id", "newId");
console.log(p.id); // 输出 "newId"

# 3.2 设置 class

js 
p.setAttribute("class", "active");
console.log(p.className); // 输出 "active"

# 3.3 设置 href

html 
<a id="link" href="#">Click me</a>
const a = document.getElementById("link");
a.setAttribute("href", "https://example.com");
console.log(a.href); // 输出完整 URL

# 3.4 设置自定义属性

html 
<div id="box"></div>
const box = document.getElementById("box");
box.setAttribute("data-id", "123");
console.log(box.dataset.id); // 输出 "123"

# 4. 与其他方法的对比

方法 功能 区别
setAttribute(name, value) 设置任意属性 支持 HTML 属性和自定义属性，直接操作 DOM 属性值不会自动同步到对象属性（如 element.id）时可能存在差异
element.id = "xxx" 设置 id 属性 更直观，直接修改 DOM 对象的属性
element.classList.add("class") 添加类名 专门针对 class，更安全（不会覆盖原有类）

总结： setAttribute 更通用，适合设置任意 HTML 属性，包括自定义属性，但对于特定属性（如 id、class、value）直接操作 DOM 对象的属性通常更方便。

# 5. 注意事项

  1. 属性名区分大小写：
    • HTML 属性通常不区分大小写（如 id、class）
    • SVG 或 XML 属性大小写敏感，需要精确匹配
  2. 与 DOM 对象属性不同：
    • 设置 element.setAttribute("value", "123")
    • 并不总是同步到 element.value（input 类型可能需要特别注意）
  3. 布尔属性：
    • 对于如 checked、disabled 的布尔属性，setAttribute("checked", "checked") 表示启用，移除属性表示禁用
  4. 安全性：
    • 避免直接插入用户输入的 HTML 到属性中（防止 XSS），尤其是 href、src 等

# 6. 高级应用示例

# 6.1 批量设置属性

js 
const img = document.createElement("img");
const attrs = { src: "image.png", alt: "图片描述", title: "提示" };

for (let key in attrs) {
  img.setAttribute(key, attrs[key]);
}

document.body.appendChild(img);

# 6.2 动态切换属性

js 
const btn = document.querySelector("button");

// 切换 disabled 属性
btn.setAttribute("disabled", "true"); // 禁用按钮
btn.removeAttribute("disabled");       // 启用按钮

💡 总结：

  • setAttribute 是 DOM 属性操作中最通用、最基础的方法之一
  • 适合修改任何 HTML 或自定义属性
  • 对特定属性，直接修改 DOM 对象属性可能更高效
  • 结合 removeAttribute 可实现动态控制属性

# JS DOM 节点获取：父节点、子节点与同级节点

# 思维导图（表格版）

一级主题 二级主题 说明 / 关键点
向上获取 parentNode / parentElement 获取直接父节点
==closest(selector)== 向上查找，直到找到符合选择器的祖先节点
向下获取 children / firstElementChild / lastElementChild 直接子节点获取
querySelectorAll 嵌套 可以递归/嵌套查询任意深度的子节点
同级获取 nextElementSibling / previousElementSibling 获取相邻的兄弟节点
组合使用 获取所有同级节点 先获取父节点，再获取父节点的 children

# 1. 向上获取：父节点

DOM 元素都在树形结构中，可以向上追溯它的父节点或祖先节点。

# 常用方法

  1. parentNode / parentElement
    • parentNode：返回父节点（可能是文档节点、注释节点等）。
    • parentElement：只返回父元素，如果父节点不是元素，则返回 null。
  2. ==closest(selector)==
    • 从当前节点开始，向上查找第一个匹配选择器的祖先元素。
    • 比如：查找离按钮最近的 .container。

# 示例：

html 
<div class="container">
  <div class="box">
    <button id="btn">Click me</button>
  </div>
</div>

<script>
  const btn = document.getElementById("btn");
  console.log(btn.parentElement); // <div class="box">
  console.log(btn.closest(".container")); // <div class="container">
</script>

# 2. 向下获取：子节点

向下获取主要是拿到一个元素的子节点，常见方法有：

  1. 直接子元素
    • children：获取所有子元素（不含文本、注释）。
    • firstElementChild：第一个子元素。
    • lastElementChild：最后一个子元素。
  2. 任意深度查询
    • querySelectorAll：可以配合选择器查找任意层级的子元素。

# 示例：

html 
<ul id="list">
  <li class="fruit">Apple</li>
  <li class="fruit">Banana</li>
  <li class="fruit">Orange</li>
</ul>

<script>
  const list = document.getElementById("list");

  // 直接子节点
  console.log(list.children);            // [li, li, li]
  console.log(list.firstElementChild);   // <li>Apple</li>

  // 任意深度子节点
  const fruits = list.querySelectorAll(".fruit");
  console.log(fruits); // NodeList(3) [li, li, li]
</script>

# 3. 同级获取：兄弟节点

如果需要获取某个元素的前一个或后一个同级节点，可以用：

  • nextElementSibling：获取下一个兄弟元素。
  • previousElementSibling：获取上一个兄弟元素。

# 示例：

html 
<ul>
  <li id="first">Apple</li>
  <li id="second">Banana</li>
  <li id="third">Orange</li>
</ul>

<script>
  const second = document.getElementById("second");

  console.log(second.previousElementSibling); // <li>Apple</li>
  console.log(second.nextElementSibling);     // <li>Orange</li>
</script>

# 4. 组合使用：获取所有同级节点

如果想获取某个元素的所有同级节点（包括它自己），需要：

  1. 先找到它的父节点
  2. 再通过父节点的 children 拿到所有子元素

如果只要「除了自己以外的同级节点」，可以用 Array.from 过滤。

# 示例：

html 
<ul>
  <li>Apple</li>
  <li id="me">Banana</li>
  <li>Orange</li>
</ul>

<script>
  const me = document.getElementById("me");

  // 先获取父节点
  const parent = me.parentElement;

  // 再获取父节点的所有子节点
  const siblings = parent.children;
  console.log(siblings); // [li, li, li]

  // 过滤掉自己，得到其他同级节点
  const others = Array.from(siblings).filter(el => el !== me);
  console.log(others); // [<li>Apple</li>, <li>Orange</li>]
</script>

# 总结

  • 向上获取：用 parentNode、parentElement 获取父节点，或用 closest() 向上查找符合条件的祖先节点。
  • 向下获取：用 children、firstElementChild、querySelectorAll 获取子节点。
  • 同级获取：用 nextElementSibling、previousElementSibling 获取兄弟节点。
  • 组合使用：通过父节点的 children 获取所有同级节点，必要时过滤掉自己。

这些方法灵活组合，可以满足大部分 DOM 节点查找的需求，例如：

  • 表格中高亮某行 → 通过同级节点控制样式
  • 菜单展开/收起 → 通过子节点查找对应元素
    • 表单校验 → 通过 closest() 找到所属的表单容器
