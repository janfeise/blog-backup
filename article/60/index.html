小心 onDrive：自动同步个人文件到工作电脑

2026.08.12 发布 5 分钟阅读 更新于 2026.10.02

背景：在公司中，我的工作电脑上竟然出现了我的个人文件，瞬间惊悚，因为我并不记得什么时候将个人的文件放置在工作电脑上😨😨😨

如何发现的？当时我想查看电脑桌面的文件分布，通过 win + r 打开 powershell 输入了下面的命令：

powershell 
 Get-ChildItem -Recurse -Depth 2

当前所在的路径：

并不是桌面，win + r 默认打开的位置不是桌面，不过那时我并没有注意到

powershell 
 C:\Users\admin>

竟然发现了，在路径 C:\Users\admin\OneDrive\文档 中存在我的个人的文档

印象中我并没有登录过onDrive，唯一的登录便是 edge，可能是在 edge 登录后，onDrive 自动弹出，我忽略了，点击登录

text 
工作电脑登录 Edge 浏览器
        ↓
登录的是个人 Microsoft Account
        ↓
Windows / Microsoft 应用已经知道这个账户
        ↓
之后 OneDrive 自动启动或弹出登录提示
        ↓
OneDrive 推荐/预填同一个 Microsoft Account
        ↓
当时没有特别注意，并点击了“登录 / 下一步 / 开始备份”等操作
        ↓
OneDrive 建立 Personal 账户
        ↓
C:\Users\admin\OneDrive
成为个人 OneDrive 同步目录
        ↓
个人云端文件开始出现在工作电脑

发现后便打开 onDrive，在设置中取消了与此电脑的关联，然后便是卸载了

卸载：快捷键 win + i，点击应用 -> 卸载 -> 卸载 onDrive
