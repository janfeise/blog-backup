loading动画分析-延迟loading

阅读时间约 6 分钟 · 字数 1151

异步请求时，页面可以使用加载动画提高用户体验，但是存在两种情况：

  • 慢接口：loading动画提高用户体验
  • 快接口（网络状态良好）：loading存在闪烁，出现又消失，造成”闪烁“

解决方案：延迟显示

初始不显示加载动画，并设置一个 200ms 的定时器，若接口在时限内请求成功，直接显示页面；若超过时限接口仍在请求，则显示加载动画

代码实现思路：

  1. 设置定时器，超过 200ms 时限触发加载动画
js 
<script setup>
const src = ref(""); // 图片src
const loading = ref(false);
let timer = null;

// 延迟加载
const lazyLoad = async () => {
  if (timer) clearTimeout(timer); // 先清理旧定时器，防止连续点击导致的逻辑混乱

  timer = setTimeout(() => {
    loading.value = true;
  }, 200); // 时限 200ms，超过时限开启加载动画

  // 接口模拟：模拟远程获取图片
  try {
    await new Promise((resolve) =>
      // setTimeout(() => resolve("https://picsum.photos/400/400"), 1000), // 1000ms
      setTimeout(() => resolve("https://picsum.photos/400/400"), 100), // 100ms
    ).then((res) => {
      src.value = res;
    });
  } catch (error) {
    console.error("图片加载失败:", error);
  } finally {
    if (timer) clearTimeout(timer); // 执行完毕，清楚定时器
    loading.value = false; // 取消加载动画
  }
};
</script>

<template>
  <el-button @click="lazyLoad">远程获取图片</el-button>
  <div v-loading="loading">
    <img :src="src" alt="图片加载中..." />
  </div>
</template>

现象：

  • 1000ms时，触发加载动画
  • 100ms时，直接显示图片，没有加载动画
